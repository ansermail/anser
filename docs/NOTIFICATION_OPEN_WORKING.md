# 系统通知点击打开邮件（2026-10-13）

## 目标与当前入口

- 用户要求点击新邮件系统通知，直接打开对应的那一封邮件内容。
- main 基于 887e297 / 0.1.13，已有打印/侧栏/草稿清空/Gmail改动保留；本轮仅本地构建与验收，用户确认前不提交远程或触发流水线。
- 旧通知只有标题/摘要，没有邮件定位或点击回调。macOS 改用 Apple UserNotifications 原生入口，全局代理注册于后台收取启动之前。

## 设计与已改代码

- 每封新邮件一条通知；userInfo仅存随机token，SQLite notification_targets绑定本机邮件ID/账号并保留30天，原始MIME不变。系统保留userInfo，退出后点击可在新进程解析。
- notification_open.rs / macos_notifications.m / build.rs 原生桥；通知点击唤醒主窗口并排队，前端先订阅再取待打开token，避免启动丢事件。最新点击覆盖尚未消费的旧点击。
- App / use-notification-mail.ts 清除遮挡目标的搜索/筛选，直接选中邮件，即使不在首屏；保留列表模式偏好但本次正文单封显示。正文成功加载后只标记目标已读。正在写信时等待关闭草稿，迟到解析不覆盖手动导航。
- 解析时核对绑定账号、期限及完整本地存档/可信活动来源；移除或不可用不猜邮件，显示错误。设置测试通知可绑定刚才阅读的邮件，便于不发信测试真实系统点击。
- 非macOS沿用原通知发送入口；本轮macOS点击定位，不宣称其他平台点击路由已实现或验收。
