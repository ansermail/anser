# UI 设计与交互专项规范

本文件沉淀 Anser（雁信）界面组件体系、视觉层级与各页面交互的专项约定。新增、调整或走查 UI 时，**须先阅读通用视觉与验收基线 [雁信 UI 设计规范（Topinspo Design Vocabulary）](../UI_DESIGN_GUIDELINES.md)**（涵盖内边距/留白/分隔、内容层级、等宽数字、长内容截断、同心圆角与细边框、WCAG 对比度、渐进展开及走查验收清单），再遵循本页的页面与控件细则。修改 UI 后须执行 `pnpm check:ui`、相关交互测试及 `pnpm build`，并在开发预览中核对实际效果。

## 1. 组件体系铁律（shadcn/ui）

**所有界面组件统一使用 shadcn/ui，禁止自行实现一套 UI 组件或混入其他组件体系。**

- **引入原则**：新增组件先检查 `src/components/ui/`；缺少时从 shadcn 官方 registry 引入，保持与现有 `new-york` 样式及 Radix 体系一致。
- **组合原则**：业务组件通过组合 shadcn 组件完成，允许业务数据、布局、尺寸与主题适配；禁止重写按钮、输入框、选择器、菜单、弹层、复选框、分栏、加载占位等基础交互组件。`src/components/ui/` 官方组件内部的原生元素属于正常实现；业务代码中的 HTML 语义结构、邮件正文 `iframe`、富文本编辑内容不属于另造 UI 组件。
- **写信 AI 助手**：遵循 shadcn AI Elements 组合模式，在 `src/components/ai-elements/` 中基于现有 shadcn/ui 基础组件实现 `Conversation`、`Message`、`ChainOfThought`、`Reasoning`、`Plan`、`Suggestions`、`PromptInput` 与 `Shimmer`；详见 [AI 功能与 Agent 协作规范](ai-and-agent.md)。
- **日期与时间控件**：
  - 日期选择使用 `Calendar` + `Popover`；时分使用组合 shadcn `InputGroup` 的紧凑可编辑数字框，支持直接输入、键盘上下键、聚焦时滚轮及输入框内上下按钮，小时限制 `00–23`、分钟限制 `00–59`。数字与调节箭头保持紧凑平衡，箭头不能贴住右边框。
  - 定时发送只能选择未来时间：早于今天的日期禁用；当天输入与调节范围从不早于下一分钟开始，越界输入恢复有效值、按钮停在边界；面板保持打开时，时间一旦过期自动推进到下一可发送分钟。界面不显示过去时间错误提示，提交函数仍须复核。
  - 禁止在业务界面使用原生 `date` / `time` / `datetime-local` 选择器，也不为小时或分钟展开 24/60 项长菜单。
- **自动补全与弹层**：自动补全用 `Command` + `Popover`（禁用原生 `datalist` 或自绘建议菜单）；确认/输入弹层用 `AlertDialog` / `Dialog`（禁用原生 `confirm` / `prompt` / `alert`）。
- **分栏**：使用现有 shadcn `Resizable` 组合，保留各区域宽度边界；普通拖动不能让区域消失，主动折叠或正文展开另按既有行为处理。
- **弹层层级**：`Popover` / `Select` / `Dialog` 等基础弹层保持 shadcn 统一层级，由 Portal 打开顺序处理嵌套；不得单独提高父弹层 `z-index` 导致子菜单被遮挡。层级验收须检查实际绘制覆盖，DOM 存在或可点击不能单独证明可见（模态 `Select` 会临时禁用父层 `pointer-events`）。

## 2. 主题、语义色与选区

- **三态主题**：保持“浅色 → 深色 → 跟随系统”三态循环；跟随系统使用 WebKit 原生配色查询并监听系统变化，偏好独立持久化。主题图标表示当前模式（浅色太阳 / 深色月亮 / 跟随系统显示器），提示文字说明下一次点击结果。
- **外观配色预设**：在应用偏好中每张主题卡片并排提供同一主题的浅色圆圈与深色圆圈（无需单独切换浅/深配色分页），两项默认均为雁信松绿并独立持久化；点击对应明暗圆圈立即应用该配色并切换到对应外观，点击主题名称同时为浅色与深色应用该主题系列并保持当前明暗模式（如跟随系统），保留状态语义色和账号色。
- **列表与导航选中态**：
  - 邮件列表选中项使用留出左右间隙的圆角背景，左侧指示竖线与上下边缘留距且两端圆润；选中背景、指示线与导航选中态通过明暗主题语义变量配对。
  - 左侧功能菜单、账号整行、服务器/本地文件夹及设置分类的当前项使用当前预设的低饱和选中背景与配对文字色，字重加强，悬停/聚焦不得覆盖已选中状态，账号颜色点保持原样。
- **全应用文字选区**：可选中文字（输入框、文本域、富文本正文及普通文本）在明暗主题下使用成对的选中背景与文字颜色；修改全局 `::selection` 时核对实际计算样式与可读对比度，避免浅色背景叠加浅色文字。
- **禁用非编辑区误选**：主侧栏（`.mail-sidebar`）、设置分类导航（`.settings-navigation` / `[data-slot="tabs-list"]`）及按钮控件禁用文字选区，并在右键时清除落入其中的选区，避免 macOS WebKit 右键触发词选出现黑色选中背景。

## 3. 侧栏、邮件列表与阅读页

### 3.1 侧栏与导航

- **分组与标签**：本地标签与本地文件夹是独立整理维度，一封邮件可包含多个标签。侧栏“我的账号 / 保存在这台设备 / 标签”使用可点击标题整体折叠，标题字号和字重高于下属入口，展开内容统一缩进；标签使用由名称稳定生成的彩色圆点。侧栏“保存在这台设备”下的本地存档、文件夹和废纸篓使用无额外行间隙的紧凑列表，单行高度保持约 `30px`。
- **账号行与服务器目录**：账号名称/地址与右侧图标共用整行圆角悬停及选中背景，保留上下留白。
- **全局滚动条按需显现**：原生滚动容器与 shadcn `ScrollArea` 默认隐藏滚动条，鼠标悬停或键盘焦点进入滚动区时显现；滚动条收窄到 4–6px，触屏设备保持可见。主侧栏保留 `scrollbar-gutter: stable`，避免滚动条显隐和目录加载改变账号行宽度。
- **侧栏滚动条空间固定**：目录加载不得改变账号行宽度。Gmail 系统分组容器在展示层展平并保留原始子目录路径；腾讯/QQ 已知“其他文件夹”容器不直接收取，历史分组提示不作侧栏告警，无子目录且被隔离的“其他文件夹”占位不展示。服务器目录按真实路径与分隔符建树；点击父项展示父项及所有可信子目录邮件，点击子项仅展示自身目录；每个账号展示星标邮件入口与去重未读数。目录加载失败仅显示简洁“加载失败，重试”，详细原因记入最近活动。
- **账号文字渐隐**：侧栏收窄后，账号名称和邮箱地址各自只在单行溢出时从右缘渐隐，拉宽到文字可容纳时恢复完整显示。悬停可查看完整文字，账号行收紧文字右侧留白，行尾箭头保留 32px 点击区域。
- **标记已读边界**：账号侧栏除收件箱、已发送、草稿箱外的服务器文件夹及账号星标邮件提供右键“标记为已读”（父目录覆盖可信子目录，不受分页/筛选限制）。已发送与草稿邮件不能标记为未读，也不进入“全部邮件”的未读筛选、侧栏未读数及 Dock/菜单栏数字。
- **全部邮件口径**：顶部“全部邮件”汇总所有账号各文件夹可阅读邮件并按邮件 ID 去重，排除本地废纸篓与被来源隔离的在线邮件；侧栏未读数、列表“未读”筛选、菜单栏与 Dock 数字使用同一全范围未读口径。
- **一级页面标题栏统一基线**：全部邮件、星标邮件、已发送、账号/目录视图、草稿箱、发送记录、工作台、通讯录、过滤规则与设置与账号共用同一左上角标题栏规范——内容区顶/左内边距统一 `18px / 20px`、标题行最小高度 `36px`（右侧有无主操作按钮均不改变行高）、`SidebarTrigger`（`28px`）与 `<h1>` 间距 `8px` 且垂直居中对齐；`<h1>` 统一 `20px` / 字重 `600` / 行高 `1.25` / 字距 `-0.02em` / `var(--foreground)` / 零外边距，辅助计数（如对话数、联系人数）以 `12px` 弱化等宽数字内联于标题右侧，切换任意侧栏一级页面不得出现图标或标题位置跳动。

### 3.2 邮件列表与搜索筛选

- **排序与标识**：邮件列表按实际时间倒序（非字符串比较），先排序再对话汇总/截取，未知时间置后；对话阅读按实际时间正序。未读点保持固定宽度不被长标题压缩，与账号颜色点明确区分；对话数量保留清晰 `Badge` 与可访问说明。
- **邮件行选择**：复选框在邮件卡片左侧随卡片高度垂直居中，勾选前后位置一致，悬停、键盘聚焦和已勾选时可见。批量动作接替筛选栏，保持邮件列表的起始位置和滚动区域稳定。
- **列表附件图标**：使用 `12px` 小图标，放在底部信息行最右侧，不紧跟账号名称，保留“包含附件”可访问说明。
- **列表行右键菜单**：与阅读面板操作保持一致——标记已读/未读、星标/取消星标、完整保存（仅未完整保存在线邮件显示）、导出原始邮件、打印、归入本地文件夹、移到本地废纸篓或恢复、回复、全部回复、转发；按当前状态显示文案并标注快捷键，不新增服务器端动作。
- **搜索与筛选弹层**：时间范围、星标/附件/“过滤已发送邮件”与搜索字段集中在搜索框旁的筛选弹层；“过滤已发送邮件”默认勾选（在“已发送”视图或具体服务器目录内不排除）。顶部不单独放时间范围按钮或空白占位行；日期条件与取消勾选默认过滤项均计入筛选启用状态；日期日历按可用弹层高度滚动，小窗口不裁掉操作按钮。搜索旁说明当前账号范围、是否排除已发送及正文只检索本机已有内容；零结果提供清除搜索与检查筛选入口。

### 3.3 阅读页、收件人与附件

- **操作分组与滚动**：主阅读页保留回复、转发与常用标记操作，打印、导出与本地归类集中到“更多 → 本地整理与导出”，服务器复制/移动单独分组。阅读标题与简短回复固定在正文滚动区之外；正文使用 shadcn `ScrollArea` 常驻可拖动滚动条，长对话不能撑出阅读面板或滚动整页。阅读区正文滚动内容四周统一保留 `10px` 外层间距（宽窄窗口与对话模式一致），HTML 正文 `iframe` 使用应用 `--radius-lg` 圆角。阅读页标签胶囊位于时间前面，标题下方不再重复。
- **收件人头部行布局**：邮件阅读页、外部邮件窗口与对话气泡按“收件人 / 抄送 / 密送”各占一行，标签列宽统一、地址列左对齐，不能把抄送或密送接在收件人同一行。任一组超过 3 个联系人时只显示前 3 项，并以可点击的 `+N` 在该字段行内展开全部地址、按可用宽度自然换行、按钮改为“收起”；不使用覆盖正文的弹层或超长整行提示。密送仅在原始邮件头实际含 `Bcc` 时显示，不推断、不留空行、不加入回复/全部回复目标。
- **联系人地址交互**：发件人及每个收件人地址逐个拆分并提供一致的悬停/聚焦底色与右键菜单（写信、复制邮件地址、复制名字和邮件地址、添加联系人）；解析失败原文保留普通文本；写信使用当前可用账号（无账号时进入添加账号流程或明确提示），添加联系人复用本地通讯录去重。
- **阅读页附件与缩略图**：使用随内容区自适应宽度的紧凑卡片，单个附件不得横跨整行。PNG、JPEG、GIF、WebP 附件默认显示真实小缩略图，使用统一 `8px` 四角圆角；透明区域直接显示卡片背景，不铺灰色或随主题变化的底板；由原生端按有界大小与像素读取生成，不向界面暴露本地路径或上传，失败回退类型图标。
- **翻译入口与悬浮提示**：翻译入口使用邮件标题行最右侧的纯图标按钮（对话模式作用于当前选中单封，其他邮件入口在各自头部最右侧），保留悬停提示、可访问名称与取消/隐藏/重试状态，不在正文上方放常驻文字按钮栏。正文图片与翻译的加载/进度/失败统一使用正文右上角悬浮胶囊栈，不参与正文流式布局、不引发布局跳动。

## 4. 写信窗口与发送预览

- **卡片布局与滚动**：完整写信正文与工具栏共用圆角卡片，左右外边距 `8px`、上方 `6px`、底部与发送栏间隔 `6px`；发送栏上方无分割线，背景从正文底色向发送栏底色纵向渐变。收件信息、正文工具栏与发送栏保持固定，编辑区、右侧预览与长引用独立滚动，正文卡片完整显示底部圆角。去掉独立「正文」标题行，全局主题在顶栏切换。正文编辑器与发送预览顶部内边距统一 `8px`，首个标题去掉默认上边距，代码块四角圆润，引用竖线为独立全圆角细条。
- **工具栏与低频格式**：标题/列表/字体/字号使用单行图标菜单及当前值提示，窄区左侧格式工具横向滚动、右侧格式选择/发送预览/导入正文图标及悬停提示保持可见。低频格式收纳到 shadcn“更多格式”菜单，长菜单限高滚动，关闭后恢复正文选区与焦点；正文文件导入明确命名为“导入正文…”。
- **右侧面板**：发送预览使用写信右侧独立面板（宽于 AI 助手），与 AI 助手互斥，窄窗从右侧覆盖；预览随正文与引用选择实时更新，关闭后焦点回到预览入口。Markdown 与 HTML 源码在正文卡片内全宽编辑，统一使用右侧发送预览。
- **单封签名与定时发送**：单封“附加邮件签名”开关位于底部工具栏、紧接“定时发送”；写作正文区不展示签名，签名仅在右侧发送预览与最终投递中展示；发送/关闭/倒计时期间禁止切换。“定时发送”使用从底部按钮上方弹出的 shadcn `Popover`，不得占正文高度或把编辑区推出窗口，按视口可用宽高约束，关闭不创建计划。
- **表格插入与上下文菜单**：必须在当前桌面窗口内完整可达。无表格时插入网格按固定 `20px` 方格与 `4px` 间距紧凑排列；行列操作分组为两列，尺寸、重置与删除在底部按单列整行展示，菜单按内容宽度收缩（插入网格右侧不留大片空白）；菜单限高不得裁掉底部操作；有表格后所有行、列、合并、表头、尺寸和删除动作直接可见，不依赖滚轮或 PageDown。
- **写信附件提醒**：仅分析当前作者可见正文（不含自动签名与引用原文），采用保守高精度匹配并排除描述性/否定上下文；选中附件、含转发文件或加入正文内嵌媒体后视为已提供。使用发送栏同行紧凑 shadcn `Alert` 提供添加附件与关闭入口；关闭只收起当前证据，发送或定时提交仍有最终确认。

## 5. 设置页、表格与弹窗

### 5.1 设置页整体布局

- 使用 shadcn `Tabs` 按 **邮箱账号、本地存档、应用偏好、阅读与写信、后台任务、关于雁信** 六类组织；轻边框、无卡片阴影、分类导航底层不铺整块灰底。
- 宽内容区左侧导航、右侧独立滚动，内容区紧贴左侧分类导航保持固定 `32px` 间距左对齐并与顶部标题网格对齐，不单独居中漂移；窄内容区改为顶部导航并保持键盘方向一致。
- 切换分类保留未保存表单；顶栏收取状态按当前界面语言显示，点击直达后台任务；同组卡片统一使用 `24px` 间距（由父容器 `gap` 管理，不叠加额外 `margin`）。
- **应用偏好**：将界面语言、后台检查、系统通知与启动、网络代理（以及工作台开关、系统默认应用）按从上到下的单列整行卡片排列（左侧标题说明、右侧控件，测试系统通知按钮在通知卡片右上角，网络代理未启用时同样展示直连说明）。
- **系统默认应用**：卡片标题为首层，默认邮件应用分组标题和邮件文件列头为第二层。扩展名与实际应用名按常规字重显示，和开关逐行对齐。默认邮件应用与文件关联使用一条细分隔线。
- **阅读与写信**：集中承载回复/转发英文引用头开关、OpenPGP 加密与密钥管理、邮件签名、AI 智能助手配置与翻译偏好；AI 智能助手卡片采用左侧说明、右侧控件的单列响应式布局，窄区上下排列。
- **关于雁信**：卡片顺序固定为关于与更新（含底部细分隔线区隔的后台收取说明）、本地诊断日志、开发版示例入口。

### 5.2 账号、存档与签名卡片

- **添加邮箱与品牌图标**：服务商选项显示完整名称（腾讯企业邮箱、网易企业邮箱），表单“返回其他邮箱”入口左对齐；添加账号与设置卡片按服务商 ID 共用本地品牌图标（官方 SVG 优先，其次官方位图，自定义或未知服务商显示通用信封）。
- **文件夹保存范围与特殊文件夹**：“服务器保留期（天，可选）”采用同行左右布局（标题说明在左、数字输入在右）；“特殊文件夹”每项固定为用途、目录选择、已识别结果三列，第三列单行省略并保留完整悬停文本，不因长路径折行割裂。
- **本地存档卡片**：同一资源的统计、完整性检查、当前位置及修改位置操作共用一张卡片，不增重复卡片。统计数字与单位使用统一 `8px` 间距并基线对齐；快速校验、深度校验、备份、恢复与导入同排自然换行，校验说明在下方并与位置管理分隔；删除入口通过分隔线与间距分开，明确区分在线邮件、临时阅读缓存与完整保存的状态文案。
- **邮件签名卡片**：顶部提供账号选择与启用开关，开启后展开；内部上下结构——顶部工具栏集中“使用 HTML”与签名文件导入，中部占满卡片宽度（启用 HTML 或导入 HTML/图片时左右 1:1 并排编辑与实时预览，标题在框体上方、两框等高对齐，窄区上下排列），底部放保存按钮与保存状态；关闭只禁用签名、保留内容。

### 5.3 TanStack Table 表格与折叠卡片

- **通用表格约束**：后台任务六组记录、过滤规则“服务器规则执行记录”与“规则处理任务”、以及发送记录，统一使用 shadcn `Table` + TanStack Table。按业务字段分列（不得重新合并为多行描述），整列为空的列、导入全零结果列及无可用动作的操作列隐藏；长文本单行省略并悬停查看完整值；所有 shadcn `Table` 使用横向 `ScrollArea`，溢出时展示 `5px` 圆角滑块，窄区只滚动表格。
- **记录表格滚动与悬停浮现**：长任务记录在表内滚动并固定表头。空间允许时，紧凑的右侧操作列固定在可视区内。导入详情、重试等常用操作常驻，次要行尾菜单在鼠标悬停、行内键盘聚焦或菜单展开时显现，保留固定点击区域。触控下直接显示操作。
- **读取反馈**：空表首次读取使用同行高、同列的骨架，后台刷新与手动刷新均保留已有记录。手动刷新在原位显示忙碌状态，抑制重复点击。保存、发现模型与清除缓存分别反馈到各自控件。
- **分页与行操作**：后台任务与过滤规则每页 10 条（刷新保留当前有效页）；发送记录表格占满工作区剩余高度，每页行数按窗口可用高度自适应且至少 15 条，超出仍分页。后台任务中导入详情直达、其余操作收拢至行尾菜单，最近活动拆出可识别的时间/邮箱/事件并支持悬停看原日志；账号移除造成的旧同步提醒只能按任务版本单独关闭并保留本地邮件与原件。发送记录多人收件显示首个地址和剩余数量（悬停及可访问说明列全量收/抄/密），详情弹层分组展示固定高度标签列表及错误/SMTP/副本诊断/改期/恢复，操作集中右下角。
- **邮件导入任务徽标与详情**：状态徽标仅按任务状态着色——“导入完成”和“导入已取消”中性，仅“导入已中断”用红色，不得因失败计数把已完成任务改红。导入详情文件名居左单行省略，逐文件结果右侧对齐状态标签，滚动容器内部包装层不得按完整文件名横向撑宽。
- **折叠卡片交互**：后台任务中的完整保存任务、服务器状态同步、目录来源检查、服务器文件夹操作及最近活动默认折叠（最近活动带用途副标题），离开设置再进保留当前窗口展开状态。后台任务与规则处理任务折叠卡片的标题、说明与箭头整块作为折叠触发区（保留键盘操作与展开状态说明）；刷新为独立按钮不得触发展开，箭头与刷新按钮相对标题说明整块垂直居中；手动刷新真实重读记录、展示旋转与忙碌文字并防连点（快速本地读取亦保留短暂可见反馈），后台自动刷新不触发手动反馈。规则处理任务展开后不追加重复解释段落或冗余入口。

### 5.4 通讯录、过滤规则与导入弹窗

- **通讯录**：使用随内容区宽度自适应的紧凑网格卡片（单列最小 `320px`，按可用宽度排 1–3 列以上），卡片仅含头像、姓名、单行省略邮箱与右侧操作，单个联系人不得横跨整行；搜索框独立一行，空态跨满网格；发件记录等其他列表不套用通讯录网格。
- **过滤规则编辑弹窗**：固定宽度，窄屏仅受视口约束；本地目标文件夹与动作选择尽量同行，上移/下移/删除统一靠最右侧；新动作菜单不提供服务器复制/移动，已有服务器规则仍可查看、编辑与执行；布尔条件值用 shadcn `Select`，邮件日期用 `Calendar` + `Popover`。
- **邮件导入弹窗与本地文件夹**：导入弹窗标签与控件同行，下拉框与名称输入框统一右对齐、最大 `320px` 并随空间收窄；仅选中文件的结果列表滚动，标题、目标、进度与底部按钮固定。本地导入文件夹提供右键重命名与永久删除（均用 shadcn 弹层，删除前明确提示仅本地永久移除、不影响服务器副本）。

## 6. 工作台（Workbench）视觉与交互

- **入口与一级导航**：入口位于侧栏底部通讯录正上方，由「应用偏好 → 工作台」开关控制（默认开启，关闭只隐藏入口并保留全部本地事项；停留在工作台关闭时返回邮件，邮件提醒入口提示先开启）。一级入口顺序固定为 **日历、四象限、事项、工作报告**，导航下方不铺分割线。
- **日历（年 / 月 / 周 / 日）**：
  - 月历保留完整卡片圆角，选中态集中在日期数字圆圈；保留上一月、下一月、年月直达与今天，年份下拉为当前显示年份前后三年并支持手输。月历导航标题与右侧当天日期标题共用同一等宽字体与等宽数字，导航标题按年/月/周/日模式预留稳定宽度，切换日期时前后箭头与今天不横向跳动。
  - 月历显示前后月真实日期与事项（弱化层级，点击切换对应月份）；网格上边与左边由外层卡片提供单线边界，首行与首列不重叠画边框；当前月用低饱和灰绿色细框与同色系浅底突出，选中日期加深一级；当天事项卡延伸至底部（无底部提醒提示区）。
  - 周/日覆盖 24 小时，进入视图或跨周/日默认定位 `08:00`（同周改选日期保留滚动位置），未选具体时间事项集中在顶部全天区，`00:00` 作为有效时间保留；今天独立描边，实时时间线仅标在今天列；周范围按钮完整容纳最长范围与下拉图标。全天与定时事件共用中性事件卡、柔和状态底色、圆角与紧凑元信息行（周视图标题单行省略，日视图允许两行，不退回单行纯字或粗左侧色条）。年览宽区四列三行，窄区三列或两列，突出当前月与今日。
  - 日历右侧当日清单在新增按钮左侧提供复制入口，输出纯文本 `yyyy/MM/dd` 换行后逐条 `序号.标题`，每条子任务按原顺序以两空格缩进加 `-- ` 紧随（含已完成事项、按时间排序，无记录禁用，复制成功/失败均提示）。
- **四象限**：使用统一二维坐标平面（纵轴重要、横轴紧急），仅保留中心轴线及上端、右端细箭头，无四张大卡片、外框、底色或网格线。事项按标题与时间自适应宽度呈胶囊横向排列自动换行；仅展示当前选中日期的未完成事项，工具栏支持切换单日并显示日期与待处理数量。重要与紧急独立维护，与优先级/状态无关。
- **事项表格与状态看板**：
  - 表格按勾选、工作事项、状态、项目分类、所属日期、优先级、重要、紧急与关联邮件拆列，默认按日期与时间倒序，每页 14 条；状态、优先级、重要与紧急使用紧凑 `Badge`，保留图标或色点语义；关联邮件列显示邮件图标与单行省略源邮件主题（悬停看全文、点击直达源邮件，无关联不留占位）。筛选集中于同一工具栏，空表隐藏勾选列。
  - 状态看板使用中性列头与卡片、普通细边框和局部状态色，列头支持按状态新增；分组同时作用于表格与看板，分组看板隐藏无记录的状态列，项目名带项目色点。
  - 右键点击任意事项行先显示整行选中态，再弹出菜单（图标 `14px`、图标文字间距 `8px`）；月历、当日清单（含已完成）、周/日全天与定时事件、四象限、看板及事项表格均提供共享 shadcn 右键删除入口，不先强制打开编辑抽屉。
- **新增抽屉与工作报告**：
  - 新增抽屉字段顺序固定为标题、状态/优先级、日期/具体时间（与定时发送共用 shadcn `InputGroup` 数字时分控件）、项目、四象限、工作内容、子任务（支持回车添加）；跨日结束日期在抽屉表面添加和移除，不藏入开始日期弹层；工作记录不包含预计/实际工时。
  - 报告使用分段日期选择、项目筛选（仅在报告范围卡操作）、双统计与页首图标操作，逐日分隔；每个日期只显示一次并按日期与时间倒序，日期内事项独立编号。

## 7. 系统菜单栏、Dock 与通知交互

- **菜单栏与 Dock**：菜单栏状态项与 Dock 角标共用“全部邮件”全范围未读数并定时刷新（零未读不显示数字）；左键菜单固定为“打开雁信 / 立即检查新邮件 / 暂停新邮件通知 / 退出雁信”，“暂停新邮件通知”写回持久偏好并与托盘勾选一致。
- **macOS Tooltip 约束**：macOS 菜单栏不创建原生悬停提示（防止后台运行时帮助标记残留在其他应用鼠标位置），周期检查不重复写入相同标题或重设 tooltip；Windows 托盘保留随界面语言切换的静态提示。
- **Windows 顶栏**：详见 [docs/WINDOWS.md](../WINDOWS.md#平台工程约束)。
