# 性能优化规范

本文件沉淀数据库并发、大列表分页与游标、全文检索、规则预筛与正文渲染的长期性能与稳定性约束，防止大邮箱场景下出现卡顿、阻塞或画面抖动。

## 1. 并发与数据库锁边界

- **本地配置即时保存**：账号名称、本地保存方式等纯本地配置必须能及时保存；后台网络收取严禁长时间持有 SQLite 写事务或全局互斥锁，阻塞阅读、写信与设置操作。
- **长 IO 移出事务**：网络请求、完整 MIME 落盘、大文件复制与 SHA-256 散列校验必须在 SQLite 写事务之外完成，仅在短事务内做代际/来源核对与原子状态发布。
- **任务并发与取消**：涉及并发操作与任务恢复时，必须覆盖过期代际结果丢弃、用户取消、账号/配置变化及进程重启恢复。

## 2. 大列表分页、对话聚合与游标稳定性

- **SQL 固定页与 WAL 快照**：分页必须先按可信来源/范围筛选并完整汇总对话，再在 SQL 截取固定页；计数、图投影、页结果与游标版本共用同一个 WAL 读取快照。
- **游标绑定与稳定性**：游标绑定筛选范围、版本号与稳定时间 + ID；数据版本变更时返回重置，禁止将旧页数据并入新结果。无变化的来源或后台状态刷新不得废弃游标；仅修改已读/星标不得重建引用图。
- **远距离连续阅读**：通过当前锚点查询邻居，不重新加载整个前缀、不跳出当前筛选范围或重复当前对话；阅读 `seek` 结果不得混入列表分页流造成缺页。
- **后台同版本刷新保尾页**：同范围、同版本的后台刷新仅更新首屏及元信息，保留用户已加载的尾页与尾部游标，不得因无变化通知把列表回退到首屏 200 条；仅范围或版本实际变化时才替换结果。稳定刷新调度通过最新工作函数执行，避免开发 HMR 长期滞留旧回调。
- **日期范围与 DST**：页面日期范围按本机日历加一天形成排他上限，正确覆盖夏令时（DST），不得以固定 24 小时代替下一天。

## 3. 全文检索（FTS）与规则/解析开销控制

- **FTS 候选索引**：搜索索引仅维护派生数据，与 `messages` 增删改同事务更新（覆盖恢复、解析修复与回滚），升级/重建不修改原件、原日期或标记。FTS 仅负责筛选候选集，最终严格保留字段与字面子串语义，禁止用户输入触发 `MATCH` 布尔语法；短词与 `NUL` 等不可完整索引记录必须精确回退，不得删改字符迎合索引；检索遵循可信来源边界，不自动下载未知正文。
- **无正文索引预筛规则**：过滤规则的历史执行与预览必须先用无正文索引筛选候选邮件，严禁一次性载入全部 MIME 原件。
- **解析升级不重解码**：解析版本升级若仅新增邮件头元数据，历史迁移不得重新解码正文或附件；在线无原件记录保留未知状态。
- **附件与远端资源有界读取**：阅读页图片缩略图、写信内嵌图片与远端正文图片/CSS/字体均须施加文件大小、像素、超时与并发上限，禁止无界读入内存。

## 4. 正文渲染、图片加载与布局防抖

- **零布局跳动的悬浮提示**：正文图片与翻译的加载、进度与失败提示不参与正文流式布局，统一使用正文右上角悬浮胶囊栈（同位置、同字号），出现、超时与移除时不得引起正文上下跳动。
- **字体回退**：远端邮件字体必须应用 `font-display: swap`，确保正文立即以回退字体可读渲染，同时保留作者字体加载完成后的样式。
- **iframe 高度防抖与循环防护**：
  - 正文 `iframe` 高度测量期间不得出现内部竖向滚动条（保持 `overflow-y: hidden`，保留横向滚动并在高度计算中补偿），防止短框滚动条挤窄宽度触发折行、拉高后折回的临界宽度死循环跳动。判定修复有效须以真实邮件 HTML 逐宽度复现与连续抓帧为准，不能只看单帧截图。
  - `ResizeObserver` 尺寸观察回调仅安排下一帧更新，并忽略 `iframe` 自身高度变化，避免循环通知。
- **图片加载超时与统计像素过滤**（按通用可见内容结构分类，不为发件人或域名打补丁）：
  - 加载占位须设明确期限，布局刷新不得延长等待；切换正文立即释放旧计时器与监听；重试仅针对失败或超时图片，保留已成功图片与原件。
  - 隐藏图片、明确零尺寸对且仍有零轴的无语义/响应式候选统计图、无内容说明且已知单边 `≤ 1px` 的排版细条不计入正文缺失告警（不得仅因未加载图片当前布局尺寸为零而排除未知尺寸真实图片；样式放大、重新显示或展开后须重新检测；裁剪判断保护内边距、最小尺寸与可逃逸定位后代）。
  - 具有明确常规透明 spacer 文件名与单像素声明尺寸的非响应式排版资源，可在净化派生 DOM 中改用本地透明像素并保留尺寸/原件；严禁将任意失败图、带内容说明图或未知/响应式图替换为空白来掩盖缺图；告警须如实报告正文图失败/超时数量。
