# README 展示截图

2026-11-28 在 Apple Silicon Mac 上使用 `pnpm desktop` 运行固定签名的雁信桌面开发版，通过 Orca 在浅色模式下重拍收件箱、写信及过滤规则。三张图均为 3840 × 2100 的 Retina PNG，保留演示标识。

| 文件 | 画面 |
| --- | --- |
| `inbox-demo.png` | 多账号收件箱与「新的一周，从一些好想法开始」邮件的阅读页 |
| `compose-demo.png` | 示例邮件的回复草稿，包含虚构收件人、格式工具栏、引用原文和草稿保存状态 |
| `rules-demo.png` | 「项目往来，自动归档」和「账单留存」两条本地归类规则 |

截图使用 `src/lib/demo.ts` 内置的虚构账号和邮件。写信画面中的收件人为示例地址，草稿仅在演示模式中保存，全程未发送邮件。逐张核对画面可见内容后移除 PNG 的 EXIF 元数据，保留原始像素和色彩配置。

`dashboard-mail.png` 是早期工作台布局的历史参考图，由 [实现记录](../IMPLEMENTATION.md) 引用。

后续若使用真实邮箱截图，必须先遮盖邮箱地址、姓名、主题、正文、附件名等关键信息，提交用户审核；审核通过后才可加入项目文档。
