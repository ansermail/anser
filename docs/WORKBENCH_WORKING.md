# 日历与多维工作台实施计划

更新：2026-11-14。工作区 `main`，基线 `9f31dc9`，保留此前 AI 首期改动。以 2026-11-13《雁信 AI 能力扩展与日历 · 多维工作台》PRD 为目标。相关阶段见 [邮件 AI 首期 PRD](AI_FEATURES_WORKING.md)。

## 阶段一：日历与本地事项

- 已实现主侧栏「工作台」（通讯录正上方）、月历、当天事项清单、快速新增和事项抽屉。月历点顶部年月直达目标月份，「今天」同时切换月份和选中日期。
- SQLite `work_items` 统一存储标题、状态、优先级、项目、所属日期、提醒时间、预计及实际工时、子任务、关联邮件和备注。保存与删除核对版本。
- 验收入口：在月历选择某日，回车新增，进入抽屉设置日期、时间和工时。退出再启动后检查事项恢复。

## 阶段二：多维表格与看板

- 已实现按状态、项目、优先级或日期折叠分组，展示每组与总体工时；表格可勾选完成、编辑状态/优先级。状态看板提供四列，通过状态选择移动。
- 验收入口：从表格勾选完成，再切换看板和月历，检查同一事项的状态和日期同步；核对工时与子任务统计。

## 日历视图与四象限补充（2026-11-14）

- 月、周、日共享日期焦点，按当前视图翻月、周或日。保留年月直达和今天。年份下拉为已显示年份的前后三年，可手输更远年份。周／日同一格的记录纵向排列，长标题在列内换行。周／日视图按全天与小时显示事项，小时格加号带入日期和小时。
- 添加用居中弹窗，编辑继续用右侧抽屉。可选择可选结束日期、具体时间、重要和紧急，继续使用原有状态、优先级、项目及其余事项字段。
- 四象限使用重要和紧急两个独立字段，象限中的添加入口预填这两个字段。旧事项默认未标记，落在「不重要不紧急」。跨日事项在各视图展示起止范围，后续日期的全天行用于表示继续进行。
- 重复规则、独立项目管理和跨日连条可继续参考截图。原生 UI 尚未验收。

## 阶段三：邮件提醒与报告

- 时间提醒随单封邮件摘要一起生成，使用现有模型、发信时间和正文。校验证据必须来自邮件原文，明确时间转换为本机时间，无时间的保留为日期。「加入日历」打开预填事项，保存后从工作台可按 ID 打开源邮件。
- 已实现日报、本周、本月和自定义区间，汇总完成状态、子任务进度和项目工时。AI 报告以事项、备注和已保存的关联邮件证据为输入。报告按日期分组，每天的事项独立编号，Markdown、打印和邮件草稿保持同样的分组，CSV 保持逐条明细。报告可通过系统打印面板保存 PDF。
- 验收入口：选择一封真实邮件，核对相对日期、时区转换和原文证据，保存后跳回原邮件；用已配置模型生成报告，核对导出和草稿。当前报告尚未自动读取关联邮件正文并生成结论，使用事项中保存的邮件证据及备注。

## 阶段四：PRD 剩余与原生验收

- 后台自动摘要、自动提醒识别、自动入表和写信自动检查尚未接入；需要在默认关闭的前提下补齐真实邮件触发、持久去重、待办写入和重试边界。当前事项提醒时间只用于工作台排期显示。
- 完成真实邮箱、现有模型、macOS 签名开发版和 Windows 布局验收。当前尚未完成原生打印、系统 PDF 保存和真实模型报告质量验证。
