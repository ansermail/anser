# Anser · 雁信 0.1.17 Alpha

## 大模型逐段双语翻译

- 邮件标题右侧新增翻译图标，保留原文，在对应段落下方显示译文；保留标题、加粗、链接、列表和表格排版。
- 邮件按钮内原文和译文上下排列，共用原来的按钮与链接，避免重复按钮。
- 设置页提供左右排列的服务、模型、密钥和目标语言配置，兼容 OpenAI 接口，支持 DeepSeek、自定义服务和本机模型；模型可手填或从服务列表选择。
- 支持取消、隐藏、重试与本地翻译缓存；连接测试使用固定文本并实际请求服务，DeepSeek 官方接口采用非思考 JSON 输出。
- 翻译批次和连接测试写入最近活动，显示结果、字数、耗时及缓存来源，不记录正文、译文、服务地址或密钥。

## 邮件图片和字体

- 原生阅读中的远端图片、背景图、样式表和字体使用应用内全局代理，改善受限网络下的加载。
- 修复透明排版占位图失效导致的整封邮件缺图误报；明确的透明占位资源使用本地像素保留排版，真实内容图片继续正常加载和反馈失败。
- 减少正文尺寸观察造成的循环警告，保留安全净化、脚本禁用与外链系统浏览器入口。

## 打印与使用说明

- macOS 原生打印面板声明简体中文；打印前等待图片完成或达到等待期限。
- API Key 仅保存在本机钥匙串。仅主动翻译时将可见正文文字发送至配置的模型服务，不发送邮件头、图片、附件或原始 MIME；译文不改写原件、回复转发或原件打印。
- Homebrew 安装命令：`brew install --cask ansermail/tap/anser`，已安装用户可用应用内更新或 Homebrew 升级；配方在正式资源核验后同步。
- 本版仍为 Alpha。应用未使用 Apple Developer ID 签名或公证，更新归档保留项目自有签名；首次打开可能需要在 macOS 隐私与安全性设置中确认。
