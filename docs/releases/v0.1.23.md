# Anser · 雁信 0.1.23 Alpha

## 中英文界面

- 在“设置与账号 → 应用偏好 → 界面语言”选择简体中文或 English，保存成功后立即生效，重启后保留。
- 侧栏、阅读与写信、账号设置、规则、富文本工具及后台任务支持中英文，日历和日期显示跟随界面语言。
- 切换语言保留当前页面、邮件选择、草稿与未保存表单；应用语言与邮件正文翻译的目标语言独立。
- 邮件原文、账号和自建文件夹名称、历史日志与发布说明保留原文，不随界面切换而改写。

## 配置与交互

- 中英文文案及语言选项集中在 JSON 配置中维护，构建时检查文案键和插值参数是否一致。
- 语言标签与下拉框同一行显示，说明文字放在下方；语言偏好独立保存，通知、同步或代理设置不会覆盖它。
- 菜单栏动作、托盘提示与系统通知的固定文字跟随语言，系统原生文件和打印面板由 macOS 的应用语言设置控制。

## 使用与更新

- 支持 Apple Silicon 与 Intel Mac，保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- Homebrew 配方继续在主仓库维护；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。
