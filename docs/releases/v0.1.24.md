# Anser · 雁信 0.1.24 Alpha

## 修复

- **收件箱实时推送漏检**：每个 IMAP 账号的收件箱改由一条长期 IDLE 监听连接独占，推送触发的下载、连接后补查、周期只读复核和定时补查都在同一会话完成，后台全目录收取跳过被监听的 INBOX。此前监听会话与短连接并存，服务端可能把新邮件通知交给随后关闭的短连接，导致实时提醒延迟或漏掉。NOOP 成功不再当作目录已刷新，新增 INBOX 的 EXISTS/UIDNEXT/UIDVALIDITY 只读复核；复核失败废弃连接，保留五分钟独立兜底。真实 QQ 邮箱与腾讯企业邮箱的 IDLE 主动推送已复验。
- **Gmail 等 OAuth 账号后台收取被判失败**：刷新令牌成功后，后台非交互写入钥匙串被系统拒绝时，不再把整次收取判为失败，也不会自动弹出授权窗口；新令牌继续在内存中使用并标记待写，只有用户主动检查、连接或保存设置时才重试写入，并提示在系统窗口中选“始终允许”。原有钥匙串内容不会被覆盖。
- **写信正文空内容时光标落在第二行**：空正文曾生成 `<p><br></p>` 形成两个行高，现在空文档只保留一行，点击正文即落在第一行。
- **收件人、抄送、密送输入行过宽**：三行输入框由整行收窄为最大 416px，窄窗口可继续收缩；“抄送/密送”入口固定在每行最右侧。
- **富文本粘贴表格被摊平**：接入官方 Tiptap 表格扩展，从网页、Excel 等位置粘贴的表格保留行列结构、合并单元格与统一边框；表格随草稿保存并写入邮件 HTML，可在发送预览中核对。
- **英文界面仍显示中文系统文字**：原生托盘菜单、工具提示、新邮件通知和发送结果通知改用与界面一致的英文键，英文界面不再回退为中文；中文界面显示不变。

## 新增

- **富文本字体颜色**：工具条的字体颜色按钮提供灰、红、橙、绿、蓝、紫、粉七种预设色和“默认颜色”，图标随当前选区颜色同步，颜色按选区应用，同一段落可混用不同颜色。邮件 HTML 保存为十六进制样式，避免 Outlook 等客户端不识别 rgb()。

## 配置与文案

- 界面文案键由中文句子迁移为英文源文案，共 1218 条中英文文案；新增文案同步维护两份语言文件，构建时校验键与占位符一致。
- 邮件原文、账号与服务器目录名称、历史日志和发布说明保持原文，不随界面语言改写。

## 使用与更新

- 支持 Apple Silicon 与 Intel Mac，保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- Homebrew 配方继续在主仓库维护；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。

## 验收边界

- 实时推送在真实 QQ 邮箱与腾讯企业邮箱复验；Gmail 钥匙串交互重写、外部代理、其他服务商及睡眠/弱网恢复仍待进一步验收。
- 系统通知横幅实际显示、托盘菜单实际点击、正式包安装与应用内原位升级、Intel 实机运行未验证。
