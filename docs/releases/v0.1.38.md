# Anser · 雁信 0.1.38 Alpha

本版新增附加存档和存档双级校验，优化大邮箱阅读性能，并包含此前尚未正式发布的翻译与排版修复。

- 新增附加存档：将超过保留期的完整原始邮件归档到外置目录，复制并校验后才移除本机副本；支持立即归档、取回本地、规范年/月目录和独立浏览器索引。账号与近期邮件继续使用本机数据，旧邮件在外置盘未连接时明确提示连接原磁盘。
- 本地存档集中显示原始邮件、内置索引大小及完整邮件数量；快速校验检查文件与大小，深度校验核对 SHA-256、MIME 和附件解码，支持后台进度、取消与持久结果，并覆盖附加存档。
- 优化大邮箱列表、搜索、单封邮件与对话读取，缓存统计并按数据变化失效，合并连续后台刷新，减少重复的全库查询与会话重建。
- 翻译请求提供准确的全部片段返回模板；模型新增、遗漏或重复片段时继续安全报错，不按位置猜配，也不自动重复收费请求。
- 普通横排链接和页尾按原段落整组显示双语，空间不足自然折行；普通 HTML 译文折叠源码缩进，按钮译文使用紧凑行高。
- 连续图片切片去除默认文字基线产生的白缝，保留作者明确的间距、换行和混合正文布局。

保留应用标识、已有账号、加密凭据库、完整邮件原件和更新公钥。提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。

附加存档已用 5,499 封真实邮件的临时副本完成归档、取回、断盘读取和校验；原生界面已核对配置、确认与断盘状态。大规模真实库、原生完整归档进度与取消、磁盘满/热插拔、Windows 与 Intel Mac 实机、正式包安装及原位升级仍待独立验收。模型仍可能违反格式模板，严格校验继续保留。
