# Anser（雁信）0.1.8 Alpha

## 收件改进

- 收件箱历史原件或邮件头下载期间，收到新的实时通知会中断当前只读下载、关闭该连接并释放收件箱任务；新一轮优先读取最新邮件，剩余历史邮件继续补收。
- 未完整收到的原件不解析、不保存，旧来源与本地原件、日期和用户标记保留。中断的连接不发送 LOGOUT、不继续其他目录；只有后续完整扫描才能核对来源消失。
- 收取活动以“本轮结束”说明当前轮次，避免让出历史下载时误称全部历史已完成。

## 配置与许可

- 原生发布流水线接入项目的 Google 桌面 OAuth Client 配置。已有 Gmail 账号若因客户端更换导致令牌刷新失败，需要重新授权；手填 Client ID 需与新配置一致。Google 测试用户限制、应用审核与真实授权/长期刷新仍需验收。
- 增加项目专用个人使用许可、授权说明与第三方许可通知。个人自用免费，包含处理工作邮件；企业统一部署、商业集成或销售需事先取得书面授权。不增加激活或付费弹窗，第三方依赖保留原许可。

## 安装与限制

沿用 `dev.maildesk.desktop` 存储/钥匙串标识、组织仓库更新地址及原更新公钥。提供 Apple Silicon / Intel 的 macOS 安装包和签名更新归档。

本轮中断保护已通过模拟 socket 与自动回归；真实繁忙收件、弱网/睡眠恢复、不同服务商及正式原位升级仍需独立验收。中断只作用于同账号收件箱的只读下载，不中断 SMTP 或服务器复制/移动，不自动重放结果不明的写操作。

仍为 Alpha，没有 Apple Developer ID 签名或公证。旧个人仓库客户端需要迁移到组织版才能使用新更新地址。
