# Anser · 雁信 0.1.28 Alpha

## 修复邮件文件偶发打开失败

- 修复 macOS 从 Finder 或“打开方式”打开 EML、EMLX、MSG 时，内容未改动却偶发提示 `fileChanged`、再次打开又正常的问题。系统写入最近使用时间等扩展属性不再被当作原件变化。
- 外部邮件与导入源仍核对文件身份、大小和修改时间；真实内容变化、同大小改写与不安全文件仍会拒绝读取。打开失败使用可读的本地化提示。

## 阅读与联系人

- 主阅读页、对话和外部邮件窗口将收件人、抄送、密送分别成行，标签与地址对齐。密送仅显示原始邮件头实际包含的地址，不推断，也不自动加入回复或全部回复。
- 发件人和每个收件人地址支持悬停高亮与右键菜单，可写信、复制地址、复制姓名和地址、添加本地联系人；有姓名时才显示对应复制项，添加联系人按邮箱去重。支持键盘 Shift+F10 打开菜单。
- 通讯录改为紧凑自适应卡片网格，宽窗口显示多列，窄窗口自动调整；长邮箱单行省略，可查看完整地址。

## 官网与演示

- 新产品官网展示完整本地留存、规则分类、历史邮件导入等功能，提供宣传片、双语介绍及下载入口。
- Web 演示独立位于官网 `/demo/`，继续复用应用界面，仅使用隔离内存中的虚构数据，不连接真实邮箱、不收发邮件、不访问本地邮件文件。

## 使用与验收边界

- 提供 Apple Silicon 与 Intel Mac 安装包及应用内更新，沿用既有应用标识和更新公钥。
- 本版仍为 Alpha，采用项目自签名；不代表 Apple Developer ID 签名或公证，首次打开仍可能需要按 macOS 隐私与安全性提示确认。
- 自动回归、云端双架构构建及发布资源审计分别记录；正式安装后的默认打开/冷启动、应用内原位升级、系统剪贴板与 Intel 实机仍需独立验收。详情见项目发布工作点。
