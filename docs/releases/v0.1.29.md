# Anser · 雁信 0.1.29 Alpha

## 代发发件人

- 当邮件的 RFC 5322 `Sender` 与 `From` 表示不同邮箱时，阅读页、对话、外部邮件窗口和打印页会显示“由 xxx 代发”。
- `Sender` 与 `From` 相同或邮件没有 `Sender` 时不显示代发信息，避免把普通发件人误标为代发。
- 在线阅读邮件的首次同步会把代发人、抄送与优先级等邮件头元数据写入本地索引；已保存原件的归档邮件会在启动迁移时只读取邮件头回填，不重新解码正文与附件。
- 阅读页与对话中的发件人姓名、邮箱地址和代发行可完整换行展示，不再用省略号截断；真实邮件内容、账号和本地存档路径不变。

## 兼容与更新

- 支持 Apple Silicon 与 Intel Mac，沿用既有应用标识 `dev.maildesk.desktop`、数据存储和更新公钥。
- 已有安装可通过应用内更新升级，Homebrew 配方继续在主仓库维护。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 签名或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。

## 验收边界

- 本版覆盖自动回归、云端双架构构建与发布资源审计；正式安装后的默认打开、应用内原位升级和 Intel 实机运行仍需独立验收。
- 云端构建、正式发布资源及 Homebrew 同步结果以项目发布记录为准。
