# 雁信待发布更新

- **Windows 安装包**。安装器使用雁信图标。双击新版 EXE 时，识别到同一用户的现有 NSIS 安装后直接覆盖原目录。旧 NSIS 安装记录若仍显示维护页，向前升级默认选中「直接覆盖安装」。 [#5](https://github.com/ansermail/anser/issues/5) @xbcmzaa
- **AI 功能开关**。在「设置与账号 → 应用偏好」关闭 AI 后，应用隐藏翻译、摘要、写信助手和 AI 工作报告入口，并取消进行中的模型请求。再次打开可继续使用已有配置。 [#5](https://github.com/ansermail/anser/issues/5) @xbcmzaa
- **过滤规则**。新增「添加标签」动作，可与归类、标星等动作按顺序组合。重复执行保留现有标签，每个标签只添加一次。
- **阅读和界面**。修正纯文本邮件正文的段落间距，统一一级页面标题和侧栏按钮对齐。规则列表每条占一行，条件与动作按可用宽度排布。README 的三张展示图更新为 macOS 浅色桌面实拍。
