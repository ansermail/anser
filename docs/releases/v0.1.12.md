# Anser（雁信）0.1.12 Alpha

## 写信与正文图片

- 新邮件及完整回复、转发默认使用富文本编辑器；旧草稿保留原格式。标题、列表、引用、代码、高亮、对齐、上下标、查找替换等工具集中在单行工具栏。
- 字体菜单提供中文和常用英文字体，字号可选；草稿和发送内容保留完整字体回退设置。
- 正文可插入 PNG、JPEG、GIF、WebP 图片。图片作为草稿自有内容保存，发送时嵌入邮件，不依赖插入后的源文件；支持调整正文显示尺寸和恢复原始尺寸。
- 调整图片尺寸的右键菜单完整显示选项；图片中的识字内容不会被当作编辑器文字选中。输入框及普通文本的选中颜色在明暗主题下更易辨认。

## 更新说明

- 更新中心将发布说明按 Markdown 显示标题、列表、代码、表格和链接；限制嵌入 HTML，桌面版的外部链接通过系统浏览器打开。

本版仍为 Alpha。正文图片在不同邮件客户端的显示、原生图片粘贴与拖拽、草稿重开及完整富文本互发待进一步实测；请先用测试邮件验证。应用继续沿用现有数据目录、标识与更新签名。尚未提供 Apple Developer ID 签名或公证。
