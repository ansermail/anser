# Anser · 雁信 0.1.20 Alpha

## 邮件工作流

- 已发送邮件可创建保留正文与附件的新草稿，原邮件保持不变。
- 写信和简短回复支持 8 秒发送倒计时，可取消并恢复编辑，也可立即发送；等待期间可继续操作其他功能。
- 发送记录使用紧凑行布局，并按最近更新时间从新到旧排列。
- 草稿箱使用紧凑卡片，便于快速浏览和恢复草稿。

## 过滤规则

- 一条规则可顺序执行最多 8 个动作，支持本地归类、完整保存、标记已读/未读、星标和本地废纸篓等操作。
- 条件支持文字包含、不包含、等于、开头、结尾，完整邮件大小、邮件日期、已读/星标状态、抄送、收件人或抄送、优先级和已接收天数。
- 抄送与优先级来自邮件原件；在线邮件缺少头信息时会等待完整保存后核对，不会把未知信息误判为空抄送或普通优先级。
- 规则弹窗使用固定宽度，目标与动作尽量同行，排序和删除操作集中在右侧；新建规则不再显示服务器复制/移动，已保存的服务器规则继续兼容。

## 未读与桌面

- “全部邮件”汇总各账号的可阅读文件夹，未读筛选、侧栏、菜单栏和 Dock 数字使用同一统计范围。
- 已发送和草稿不显示、也不计入未读，账号侧栏对应目录不再提供“标记为已读”。
- 菜单栏与 Dock 显示未读数字；托盘菜单支持打开应用、立即检查、暂停通知和退出。
- 账号下的服务器文件夹继续提供右键“标记为已读”，父目录按可信子目录汇总。

## 使用与更新

- 保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- 首次通过 Homebrew 安装使用 `brew install --cask ansermail/tap/anser`；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名和更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。
