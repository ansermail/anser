# Anser · 雁信 0.1.25 Alpha

## 修复

- **通知重复点击沿用旧的阅读位置**：点击通知按该条通知绑定的单封邮件重新定位；重复点击同一条通知也从正文开头显示，保留当前写信草稿与迟到请求保护，只标记目标邮件已读。旧通知仍指向原来的邮件，不按相同主题猜测或跳到另一封。
- **长对话打开后显示较旧邮件或正文末尾**：改为定位所选单封的开头，前面邮件的正文、图片异步加载后继续保持该位置。修复 WebKit 将 iframe 布局变化引起的滚动误判为用户滚动的问题；用户通过滚轮、拖动或滚动键开始浏览后，不再强制拉回。
- **阅读区随长对话溢出**：明确正文滚动边界，顶部邮件信息与底部简短回复栏保持固定，只有邮件内容区域滚动。

## 阅读体验

- **常驻正文滚动条**：单封邮件和对话均使用 shadcn ScrollArea，右侧始终显示可拖动滑块，长邮件与多封对话可以快速定位。
- **对话数量 Badge**：列表中的邮件数量改为更清晰的圆角描边 Badge，补充中英文可访问说明，例如“此对话包含 41 封邮件”。

## 使用与更新

- 支持 Apple Silicon 与 Intel Mac，保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- Homebrew 配方继续在主仓库维护；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。

## 验收边界

- 开发预览已核对真实 41 封对话的最新邮件、数量 Badge、正文滑块及固定头尾；自动回归覆盖通知重复定位、迟到请求和异步正文加载。
- 系统通知横幅实际点击、正式包安装与应用内原位升级、Intel 实机运行尚未复验，不能用开发预览或构建结果代替。
