# Anser（雁信）0.1.11 Alpha

## 附件转发

- 普通转发自动准备原邮件附件，可逐项选择，保留同名文件、原始字节和 MIME 类型；准备失败会明确提示，发送前核对副本，不静默漏掉附件。
- 草稿关闭或重启后保留附件与选择；取消定时计划恢复独立草稿副本，结果不明时不自动重复发送。
- 写信窗口接入原生文件拖拽，重复路径去重，保留不同目录的同名文件；发送、关闭和倒计时期间不接收。网页示例不读取真实文件。
- 修复发送、定时提交、保存或舍弃之后草稿页仍展示旧卡片的问题；原附件选择区保持统一内边距，长文件名可换行。

## 阅读快捷操作

- ⌘R 回复、⌘⇧R 全部回复、⌘⇧F 转发，均只打开草稿，不自动发送。
- ⌘⇧U 切换当前邮件已读状态、⌘⇧L 切换星标；不隐式修改整个对话或多选，仍支持撤销。
- 按钮悬停提示与全部回复菜单显示快捷组合。输入、IME、弹层/菜单、重复按键、正文切换和过期范围不抢按键；写信中不会因 ⌘N 替换未完成草稿。

## 候选版验收状态

本版当前用于 GitHub 草稿构建，尚未作为公开更新发布。授权双邮箱小附件发送、选择转发和草稿重启已验证；冻结发送原件的附件字节一致。新增快捷操作的交互回归及纯虚构浏览器按键通过。原生系统拖拽、原生快捷键及定时取消等实际样本尚待确认，不能把模拟事件当作系统验收通过。

真实大附件/弱网/睡眠/磁盘等矩阵、正式安装及原位升级仍待完成。应用仍为 Alpha，未有 Apple Developer ID 签名及公证；更新包继续沿用现有更新签名。
