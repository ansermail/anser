# Anser · 雁信 0.1.47 Alpha

- 应用偏好新增 10 套浅色与深色外观配色预设，浅深主题分别保存并同步至邮件正文与工作台日历；全部 20 套明暗配色通过 WCAG 2.2 AA 对比度校验。
- 写信「AI 助手」移除外部对话运行时依赖并全面重构为纯 shadcn/ui AI Elements，新增可折叠思考链、模型思考过程（支持读取兼容模型 `reasoning_content` 与 `<think>`）与结构化修改计划卡片，同时修复空白草稿多段 Diff 预览换行与底部 Toast 撤销操作。
- 恢复 AI 邮件摘要浮卡右上角悬浮定位（正文滚动不位移且与翻译状态胶囊上下错开不重叠），并将双语翻译样式调整为无左侧竖线、与原文左对齐的柔和微底色圆角块。
- 全面打磨邮件列表、阅读工具栏、过滤规则、本地存档、发送记录与工作台的排版对齐、空态、加载骨架、焦点无障碍及窄窗适配，并保留写信富文本段首缩进与连续空格至发送预览与发出邮件。

提供 Apple Silicon、Intel Mac 和 Windows x64 安装与更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
