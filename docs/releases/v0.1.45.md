# Anser · 雁信 0.1.45 Alpha

- 修复设置 → 阅读与写信「AI 智能助手」卡片在默认桌面宽度下的双列排版溢出，补齐深浅主题 `--muted-foreground` 与 `--ring` 语义变量（恢复列表复选框边框、聚焦环与弱化文案层级），并修正下拉选择器长文本省略号。
- 修正深色模式写信窗口的收件人/主题输入透明融合与切换主题时的富文本画布实时同步，修复写信会话关闭异常与 Windows 附件文件名展示，优化简短回复与发送队列竞态。
- 修正过滤规则提示条「对已有邮件执行」按钮对齐与多步骤服务器规则保存校验，将通讯录搜索图标内嵌至输入框左侧，补齐发送记录详情弹层滚动以及 1000px 窄窗下的阅读与周历工具栏适配。
- 工作台「日期」与「具体时间」统一为等高单行布局并采用正向开关，将 24/60 项时间长下拉替换为与定时发送共用的紧凑数字时分框，结束日期保持纯日期选择。
- 修复邮件列表乐观状态覆盖后续同步、切换邮件时收件人串档与展开态残留、侧栏标签/文件夹双高亮及设置隐藏页签持续轮询，并补齐多处中英文文案与系统测试通知本地化。
- 优化桌面后端数据库与同步稳定性：无变化 IMAP 同步不再破坏分页游标或重建会话图，按需回填冷启动列表索引，为消息索引与整文件夹标记已读提速，修复 IDLE 监听重启归属竞态与异常协议响应防护。
- 优化发送记录、定时轮询、远端正文资源连接复用、附件缩略图缓存及异步桌面命令响应；托盘退出先等待发件落库并保存窗口状态，重复打开同一外部邮件文件时恢复已有窗口。

提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
