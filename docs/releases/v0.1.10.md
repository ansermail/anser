# Anser（雁信）0.1.10 Alpha

## 搜索与邮件列表

- 本地标题、发件人、收件人和已有正文建立全文候选索引；中文、短词、引号和字面符号继续精确检索，不自动下载在线正文，不修改原始邮件。
- 逐封与对话模式改为后端固定页，解除界面累计5000条限制。加载更多只请求下一页；数据版本改变时自动重置，后台无变化刷新保留已加载页。
- 对话计数保留完整引用图/服务器副本去重语义；范围内汇总未读、星标和附件，再选择最新代表。不把不同账号或相同主题误合并。
- 上一封/下一封可从当前阅读位置直接查找，远距离阅读无需重载整个前缀；保留当前筛选、跨页阅读、迟到响应保护，跳转结果不混入列表页流。

## 时间与正文范围

- 增加时间范围日历，使用本机时区并包含起止日期；可重新选择、不限时间，时间未知邮件不参与日期筛选。
- 全部字段/正文检索提供本机已有正文覆盖说明；需要纳入完整正文搜索时可主动选择完整保存，搜索本身不会自动下载。
- 索引升级、恢复和解析修复同事务维护派生数据，保留原件、日期、标记和来源；短词与不可完整索引的NUL文本使用精确回退。

## 验收范围与限制

单机五万条合成Store记录的Release模式测量通过：固定首页200条，逐封/对话首屏满足3秒、所测标题/正文（含两字扫描）首批满足1秒。数据包含1800/36000字节虚构文本、约2/3已保存、20发件身份、跨34天/未知日期与引用对；操作系统缓存未清空，不能代表真实磁盘冷启动、多Mac或繁忙网络验收。

提供Apple Silicon/Intel安装包和签名更新归档，继续沿用存储/钥匙串标识、更新公钥与组织仓库地址。仍为Alpha，无Apple Developer ID/公证；实际原位升级、多Mac/弱网/睡眠及服务商矩阵继续独立验收，后续附件体验等仍在开发。
