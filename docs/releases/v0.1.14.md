# Anser（雁信）0.1.14 Alpha

## 阅读与通知

- macOS 新邮件系统通知绑定具体邮件，点击后直接打开对应正文；应用隐藏或退出后点击也支持定位，写信期间保留草稿并延后打开。
- 正文图片加载等待最多15秒，之后收起占位条，提供失败或超时图片重试。隐藏图片和1×1统计像素不再导致正文加载误提示，图片稍后成功时提示自动消失。
- 阅读正文右键“检查元素（Inspect Element）”可打开WebView开发者工具，查看Console和Network。邮件脚本仍禁用。
- 修复邮件打印被原生权限拦截的问题；打印入口仍位于星标与本地删除之间，仅打印当前单封邮件。

## 目录与草稿

- 账号行增加上下留白与圆角，账号信息和图标共用整行悬停/选中背景；目录展开时保持侧栏宽度稳定。
- Gmail 的系统文件夹直接与收件箱平齐展示，隐藏中间的“[Gmail]”分组。完整目录加载后不再因退出连接回执误判失败；失败仍显示“加载失败，重试”，具体原因保存在设置的最近活动。
- 腾讯企业邮箱和QQ邮箱的“其他文件夹”按分组处理，汇总可信子目录邮件；没有子目录时不显示空分组，已知分组根目录的旧警告不再显示在侧栏。
- 本地草稿箱增加“清空草稿”入口，确认数量后清空；正在编辑、已进入发送流程或确认后内容变化的草稿受保护。该操作不清理服务器草稿或用户原文件。

本版仍为Alpha。沿用现有账号、存档标识和更新签名。尚未提供Apple Developer ID签名或公证，正式包原位升级和长期通知/网络使用仍需实际验证；第三方图片服务器不可用时不能保证图片显示。
