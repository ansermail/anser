# Anser（雁信）0.1.7 Alpha

## 新功能

- 保存范围增加服务器数量与磁盘预算检查：按当前选择只读核对邮件编号/原件大小，显示未缓存位置、预计待保存数量与实际存档磁盘空间，空间不足或检查不完整明确提示。支持取消，关闭/切账号/改范围废弃旧结果；不自动下载邮件或修改范围。
- 过滤规则增加“完整保存”和“完整保存并归入本地文件夹”。在线正文/附件未知条件先按需核对，再执行匹配动作；历史规则任务支持暂停、继续、取消及明确失败重试。
- 规则链持久化顺序与代际保护；保存原件与本地分类成功后才允许关联的服务器复制/移动提交，结果不明不自动重放。

## 改进与保护

- 完整原件准备、写入和校验移出 SQLite 写事务；短事务发布前重验账号、来源、配置和任务，失败不产生假的完整保存状态。
- 删除应用内“打开 EML”按钮。仍可从 Finder 的“打开方式”选择 Anser（雁信）打开外部 `.eml` 文件，保持只读查看与附件预览/另存。
- Pages 继续共用桌面界面与虚构数据，禁止真实服务器预算检查、磁盘访问或异步下载。

## 安装与限制

提供 Apple Silicon 与 Intel 的 macOS 安装包和签名更新归档；沿用 dev.maildesk.desktop 应用/钥匙串标识、组织仓库更新地址及原更新公钥。

预算是检查时的估算：服务器大小可能有差异，多个目录的同一邮件可能重复计入；增加 10% 与 128 MB 余量，不代表实际保存或磁盘写入已验收。每个目录最多检查 20 万项，检查总截止时间为 90 秒；未知/不完整结果不当作零。大附件、外置盘故障、其他服务商、繁忙到达和正式原位更新仍有待验收项。

仍为 Alpha。没有 Apple Developer ID 签名与公证，本机 OAuth 测试配置不进入公开包。旧个人仓库客户端需迁移到组织版才能使用新更新地址。
