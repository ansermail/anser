# Anser · 雁信 0.1.35 Alpha

新增 Windows 客户端，与 macOS 共用本地优先的邮件管理和完整存档能力。官网提供 Windows/macOS 下载切换，并默认展示当前电脑系统的安装包。

## Windows 客户端

- 新增 Windows 10/11 x64 客户端，使用 WebView2、融合式窗口顶栏、Ctrl 快捷键和每用户 EXE 安装器。
- Windows 顶栏按应用布局融合，右上角提供最小化、最大化/还原和关闭，去掉重复的标题栏图标与应用名。
- 修复 Windows 顶部多余的 File/Edit 默认菜单和双击启动附带终端；主窗口最小化/关闭后继续在系统托盘运行，点击图标恢复。
- 与 macOS 共用邮件协议、界面及原始 MIME 存档；加密凭据库的密钥保存在 Windows Credential Manager。
- 适配正文图片、样式、字体和安全外链，支持独立打开 EML/EMLX/MSG 邮件窗口。
- 安装器只注册可选邮件处理程序及通知协议，保留用户原有默认应用选择；默认应用由用户在系统设置中选择。
- 增加 Windows 安装、首屏、外部 EML 及原生外链点击冒烟，收紧脚本、安装器与快捷方式附件的直接预览边界。

## macOS 回归与发布边界

保留现有应用标识、账号、凭据、存档和更新公钥。修复 Mac 打印页顶额外留白与正文意外缩小，默认 A4、100%、16mm；修复独立邮件窗口打印长邮件只输出第一页，保留原格式并完整分页。构建、签名与原生回归结果在开发记录中分别记录。

本版资源包括 Apple Silicon/Intel Mac DMG 与更新归档、Windows x64 EXE 及更新签名和三平台更新清单。

Windows 没有 Authenticode 发布者签名，系统可能显示未知发布者；Tauri 更新签名不等同于 Windows 发布者签名。Mac 沿用固定免费项目自签身份，不等同于 Apple Developer ID 或公证。用户已在 Windows 实测邮件发送与打印；代理完成 Windows 11 窗口、草稿、系统通知横幅和外部邮件检查。实时 IDLE 新到达、绑定邮件通知冷启动、原位升级、Windows 10 实机及 Mac Intel 实机仍未验证。
