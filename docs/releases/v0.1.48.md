# Anser · 雁信 0.1.48 Alpha

- 邮件深色阅读会调整正文的中性底色、边框和文字对比度，并让符合条件的黑白字标在深色背景上清晰显示。切换主题或单封原始配色时，正文原地过渡并保留阅读位置。加载失败的正文图片显示统一的占位图标，可在阅读区重试。
- 每套外观预设并排展示浅色和深色色样。空阅读区增加轻量动效、时段问候及收取反馈，点击雁信标志可检查新邮件。
- 邮箱账号支持拖拽排序及菜单上移、下移。重新展开已加载的账号目录时会复用会话缓存。
- 提供单封收取失败的重试、仅保留在线邮件头和跳过选项。改进腾讯企业邮箱连接和诊断反馈，并支持导出脱敏的本地诊断日志。
- 整理「关于雁信」中的更新与项目入口，方便查看和检查新版本。

提供 Apple Silicon、Intel Mac 和 Windows x64 安装与更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
