# Anser · 雁信 0.1.44 Alpha

- 富文本与 Markdown 写信共用可视化表格编辑，支持插入、合并、表头、精确尺寸、行列拖拽、整表缩放和发送预览；代码块、引用与表格采用圆角排版。
- 定时发送改为悬浮面板，小时和分钟使用紧凑可编辑数字框。过去日期不可选，当天过去时间不能输入或调到，计划时间过期后自动推进；不再为过去时间显示错误提示。
- 收件人、抄送和密送超过 3 个联系人时显示 `+N`，点击后在当前字段行内展开完整地址，阅读页、对话和外部邮件窗口保持一致。
- 阅读页附件恢复紧凑自适应卡片，PNG、JPEG、GIF、WebP 默认显示带圆角并保留透明背景的真实缩略图。
- 添加账号和设置页使用 Gmail、Outlook、Microsoft 365、QQ 邮箱、腾讯企业邮箱与网易邮箱的本地官方品牌图标。
- 深色阅读保留邮件作者的多行品牌页脚、字标和原配色；普通正文继续跟随应用主题。
- 文本书写区域以外的 Backspace 不再触发 WebView 返回空白页，并为应用主窗口和外部邮件窗口增加渲染异常恢复入口。
- 文件夹保存范围、特殊文件夹、服务器同步表、窄窗口侧栏与阅读工具栏完成紧凑布局修正。

提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
