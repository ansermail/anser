# Anser · 雁信 0.1.43 Alpha

- 工作台的月历事项、当日清单、周/日事件、四象限、看板及事项表格新增右键删除，无需先打开编辑抽屉；删除前仍需确认。
- 周/日视图默认从 08:00 显示，保留全天 24 小时滚动。今天有独立描边，今天所在列显示随时间移动的红线和圆点。
- 年历宽屏以四列三行展示全年 12 个月，窄窗自动调整列数，并突出当前月和今天。
- 四象限可直接切换日期、选择指定日期或返回今天，坐标轴补充重要和紧急标识，新增入口靠近象限计数。
- 事项搜索、状态、分组和项目筛选集中在同一工具栏。看板支持按列新增及拖到另一状态列保存。
- 工作报告移除重复的筛选与日期标题。编辑抽屉直接提供结束日期入口，并将项目管理放到项目标签旁。
- 修复当前时间线因缺少颜色变量而透明的问题，并改善工作台空态提示。

提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
