# Anser - 雁信 0.1.49 Alpha

本版加入 OpenPGP 签名与端到端加密，修复发送撤销提示、收件期间暂停账号，以及 Windows 工作台抽屉关闭按钮被遮挡的问题。

## 主要变化

- **OpenPGP 签名与加密**。在「设置 → 阅读与写信」管理 OpenPGP 密钥，写信时可签名、加密并检查收件人公钥。阅读邮件时，点击时间旁的锁形图标可查看解密、验签和密钥指纹。加密邮件禁用 AI 功能，PGP/MIME 协议封装从附件显示中排除。
- **发送撤销倒计时**。完整写信和简短回复的撤销提示按待发队列截止时间逐秒更新。到期、提前发送或取消后，提示自动关闭。倒计时内点击「撤销」可以恢复草稿。
- **收件期间暂停账号**。暂停可中断该账号正在进行的收取，其他账号继续运行。主动暂停产生的取消结果不再记录为收取失败。
- **回复、转发和翻译**。新增英文 RFC 引用头选项。双语翻译保留行内代码与链接，改善译文标题和列表的留白与圆角。账号连接和代理错误会指出连接失败的阶段。
- **Windows 布局**。工作台等抽屉避开窗口标题栏，关闭按钮可以正常显示。系统默认应用设置卡片的标题与其他卡片对齐。

本版提供 Apple Silicon、Intel Mac 和 Windows x64 安装与更新资源。macOS 安装包使用雁信项目的自签名证书，首次打开可能需要在系统设置中手动允许。
