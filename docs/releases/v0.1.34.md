# Anser · 雁信 0.1.34 Alpha

## 邮件打印保留原始格式

- 修复打印预览丢失邮件样式、标题字号、背景与段落间距的问题。打印保留完整安全净化文档，在独立样式边界中排版，保留原邮件的字体、颜色、表格与结构。
- 打印前有界等待正文图片、样式表与字体，自定义字体使用临时私有名称，避免影响应用界面。
- 长邮件按纸张正常分页，保留完整正文、邮件头及附件名称。

## A4 正常比例

- 默认 A4 纵向、100% 缩放与 16mm 页边距，从页顶开始排版；超宽内容适配可打印宽度。
- macOS 每次创建独立打印参数，避免沿用旧缩放或居中设置；系统面板直接显示纸张大小、方向与缩放，支持调整本次任务。

沿用现有应用标识、账号、本地存档和更新公钥。原邮件与附件字节不变，打印仍经过安全净化。网络资源加载失败或超时可能影响显示；纸张宽度会改变换行及分页。

项目仍处于 Alpha。macOS 安装包使用固定的免费项目自签名与 Tauri 更新签名，不等同于 Apple Developer ID 签名或公证。真实纸张打印、应用内原位升级和 Intel 实机仍需独立验收。
