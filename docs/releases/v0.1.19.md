# Anser · 雁信 0.1.19 Alpha

## 正文图片提示

- 所有邮件共用可见正文图片判断，排除隐藏统计图、零尺寸资源和排版占位图的误报，不按发件人或图片域名单独适配。
- 修复 WebKit 为失败的 0×0 统计图生成占位框，导致正文图片已完整显示仍提示失败的问题；补充明确裁剪和折叠内容的判断。
- 被样式放大或重新显示的图片会重新检测，真正未加载的正文图显示数量及失败/超时分类，并保留重试。未知尺寸、有内容说明及响应式图片继续检测；不改邮件原件。

## 完整升级记录

- 更新中心显示当前版本至目标版本之间所有适用已发布版本的完整说明和实际版本数，按版本倒序展示，不再只显示最新版内容。
- 历史查询失败时明确标注说明尚不完整，并可单独重试；不影响已验证更新包的下载、签名校验及写信保护。

## 钥匙串与固定应用签名

- 邮箱凭据、OAuth 令牌、代理密码和模型 Key 共用一个受保护的本地钥匙串凭据库。每次应用会话最多进行一次交互式初始化，后续操作和旧条目迁移不再逐账号弹出授权。
- 使用固定免费的项目自签名，本地与 GitHub 的 Apple Silicon / Intel 构建保持同一签名身份，减少应用代码变更带来的重复授权。
- 首次从旧签名版本升级，macOS 仍可能要求为统一凭据库授权一次；可在确认属于雁信后选择“始终允许”。旧条目若无法无交互迁移会保留，需重新连接对应账号或填写配置，不自动连续弹窗。

## 使用与更新

- 保持应用标识、账号、存档、原始 MIME 及既有更新公钥不变。
- 首次通过 Homebrew 安装使用 `brew install --cask ansermail/tap/anser`；已有 Homebrew 安装先运行 `brew update`，再运行 `brew upgrade --cask ansermail/tap/anser`。手动安装用户可使用应用内更新。
- 本版仍为 Alpha。固定项目自签名和更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要在 macOS 隐私与安全性设置中确认。系统锁定或拒绝授权时仍需按系统提示处理。
