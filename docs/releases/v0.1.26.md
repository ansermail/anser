# Anser · 雁信 0.1.26 Alpha

## 设置与体验优化

- **设置页整体左对齐与六分类导航**：取消宽屏下右侧设置面板脱离左侧分类栏的独立居中漂移，内容区紧贴左侧分类导航保持固定间距并与顶部「设置与账号」标题网格对齐。设置导航扩充为「邮箱账号 / 本地存档 / 应用偏好 / 阅读与写信 / 后台任务 / 关于雁信」六类，将「邮件签名」与「大模型翻译」归入独立的「阅读与写信」分类，切换分类继续保留未保存输入。
- **应用偏好单列整行布局**：「界面语言」「后台检查」「系统通知与启动」「网络代理」改为从上到下的单列整行卡片，左侧展示标题与说明，右侧对齐对应交互控件；「测试系统通知」按钮移入通知卡片右上角，网络代理未启用时展示直连状态说明。
- **邮件签名上下结构与对称预览**：开启签名后，顶部工具栏集中放置「使用 HTML」开关与「签名文件」导入控件；中部全宽展示编辑区（开启 HTML 或导入 HTML/图片时左右 1:1 等宽、等高、一致圆角并排展示编辑与实时预览）；底部放置「保存签名」按钮与「已保存 / 尚未保存」状态标识。
- **邮件筛选默认过滤已发送邮件**：在搜索栏旁的「邮件筛选」弹层中新增默认勾选的「过滤已发送邮件」选项；在「全部邮件」等综合视图下默认不混入已发送邮件，取消勾选后可一并展示，「已发送」与具体服务器文件夹视图不受影响。
- **导航与按钮右键防误选**：禁用左侧主导航栏、设置分类导航与按钮控件的文字选区，并在右键拦截时清除落入导航/按钮控件内的残留词选，修复 macOS WebKit 右键点击导航项出现黑底字符选中的问题；正文、输入框与编辑区保持正常文字选择。

## 使用与更新

- 支持 Apple Silicon 与 Intel Mac，保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- Homebrew 配方继续在主仓库维护；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。
