# Anser · 雁信 0.1.40 Alpha

本版集中改善界面的视觉层级、阅读稳定性与常用操作路径。

- 阅读工具栏优先显示回复、全部回复和转发；打印、导出与本地归类收进“更多 → 本地整理与导出”，服务器复制/移动使用独立分组。
- 搜索框旁明确当前账号范围、是否排除已发送以及正文是否只覆盖本机已有内容。零结果时可直接清除搜索或检查筛选条件；保留旧正文时会提示其不在当前搜索结果中。
- 正文图片加载、失败重试与大模型翻译进度统一为右上角悬浮胶囊，使用相同位置和字号，不占正文布局高度。图片完成、失败或翻译结束不会推动正文上下跳动。
- 远端邮件字体使用 `font-display:swap`，正文先以回退字体立即显示。深色阅读中略带色相的近黑标题保持可读，同时保留作者品牌色、彩色底面和背景图；单封正文可切换原始浅色配色。
- 邮件列表当天显示时间、同年显示月日、跨年显示年份，完整时间保留在悬停和阅读头部；没有摘要的邮件不再留下空白行。
- 阅读缓存、在线邮件与完整保存的状态说明更明确。存档统计数字与单位统一间距，校验、备份、恢复和导入集中排列，删除入口独立分隔并说明风险。
- 过滤规则统一命名并提供明确空态入口；写信低频格式收进“更多格式”，正文文件入口改为“导入正文…”。

保留现有品牌色、应用标识、账号、加密凭据库、完整邮件原件、附加存档和更新公钥。提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。

本版不改变邮件协议、原始 MIME、打印或转发内容。Windows 实机、Intel Mac、更多邮件模板以及正式包原位升级仍需独立验收；macOS 分发包继续使用固定免费的项目自签名，未使用 Apple Developer ID 签名或公证。
