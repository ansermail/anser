# Anser · 雁信 0.1.27 Alpha

## 邮件导入与本地管理

- **多格式本地导入**：可将 EML、EMLX、Outlook MSG 和 MBOX（含 `.mbx`）导入现有或新建的本地邮件文件夹。每批最多 1,000 封邮件，所选文件合计不超过 1 GiB，单封不超过 64 MiB。
- **完整原件与后台任务**：导入邮件保留原始字节，按账号和原件散列去重；已有邮件补全原件时保留原 ID、日期、标记和分类。任务可在后台继续、取消或清除记录，取消保留已完成部分，异常中断后需重新选择文件。
- **本地分类管理**：导入文件夹支持右键重命名和永久删除。删除文件夹会同时移除其中邮件的本地记录、分类、来源关系及不再被其他邮件共享的原件，不发送服务器删除命令；服务器邮箱中的副本不受影响。
- **格式关联与外部阅读**：设置中的「格式关联」可将 EML、EMLX、MSG 直接交给雁信打开。外部单封邮件使用具备 macOS 原生窗口按钮的独立阅读窗口，复用普通邮件头、安全正文、附件、打印、回复、全部回复和转发；上一封/下一封展示但禁用。

## 主题与阅读

- 右上角主题按钮按「浅色 → 深色 → 跟随系统」循环。太阳表示浅色、月亮表示深色、显示器表示跟随系统，提示文字说明当前模式及下一次点击结果。
- 跟随系统时，雁信随 macOS 外观即时切换。邮件正文和写信源码预览同步明暗主题；深色正文使用与邮件信息栏一致的应用背景，同时保留作者品牌色、背景图和正文图片。浅色与打印保持白底深字。

## 使用与更新

- 支持 Apple Silicon 与 Intel Mac，保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- 邮件导入只写本地存档，不上传至网页邮箱、服务器或移动设备。MBOX 支持常见 mboxrd/mboxo；含 Content-Length 的 mboxcl/cl2 需转换后导入。PST 不在本版范围。
- 普通 MSG 的文本、HTML、CID 和二进制附件可读取；嵌入邮件、OLE 附件及仅含 RTF 等特殊变体明确提示暂不支持。
- Homebrew 配方继续在主仓库维护；已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。

## 验收边界

- 本版已在本地自动回归与 macOS arm64 开发预览中核对多格式导入、原件导出、本地文件夹管理、格式关联、独立外部邮件窗口、三态主题及正文明暗适配。
- 正式安装后的默认双击/冷启动、应用内原位升级和 Intel 实机运行仍需独立验收；云端构建、正式发布资源及 Homebrew 同步结果以项目发布记录为准。
