# 雁信 0.1.0 Alpha

- 多账号 IMAP/POP3 收取、SMTP 发送、草稿与定时发送。
- HTML、Markdown、富文本写信，附件本地预览。
- 服务器文件夹、邮件回复对话、本地存档及备份。
- 三栏宽度限制、搜索与组合筛选。
- 新增 GitHub Release 更新中心：检查、下载、签名校验、安装并重启。

此版本仍为 Alpha。完整待办与验收范围见仓库开发计划。

下载与 CPU 对应的 DMG 进行首次安装。后续通过应用内更新中心更新，无需再次拖动应用。
当前未做 Apple Developer ID 签名及公证，首次启动可能需在 macOS 系统设置中确认允许打开。
