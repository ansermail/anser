# Anser · 雁信 0.1.39 Alpha

本版重点改善在线阅读体验：邮件头不再等待正文，远程正文和附件可以在本机短期复用。

- 打开邮件后立即显示发件人、收件人、主题、时间和操作栏，正文区域单独加载；正文失败时保留头部并显示“正文加载失败”和重试入口。回复、转发、打印与“编辑为草稿”在正文就绪前禁用。
- 新增独立阅读缓存：在线阅读成功取回的完整 MIME 会写入应用数据根的 `read-cache/`，再次打开、查看附件或打印时优先复用。默认保留 30 天、容量 1 GB，可在“设置与账号 → 应用偏好 → 阅读缓存”关闭或选择 7/30/90/365 天及 256 MB–4 GB。
- 保留时间按最后一次打开计算；超期、超过容量、邮件身份变化或缓存文件校验失败时自动清理并重新从服务器读取。容量不足时优先移除最久未打开的邮件，关闭缓存后每次在线阅读都重新访问服务器。
- 阅读缓存不改变“完整保存”状态，不计入存档统计、备份、完整性校验或附加存档；完整保存成功后删除该邮件缓存，移除账号时清理对应缓存，设置页可查看占用并手动清除。
- 修复后台检查与阅读缓存两张偏好卡片可能用旧状态覆盖其他设置的问题；保存时先读取最新偏好，只更新当前卡片负责的字段。

保留应用标识、已有账号、加密凭据库、完整邮件原件、附加存档和更新公钥。提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。

已在原生开发预览核对在线阅读邮件头部立即显示、正文骨架、两封在线邮件生成缓存及再次打开命中缓存；自动测试覆盖过期、身份变化和容量淘汰。缓存过期/关闭后重新拉取、完整保存后缓存移除及清除确认仍需真实操作补验；断网、磁盘不足、大附件、Intel Mac、Windows 实机与正式包原位升级未在本轮验证。
