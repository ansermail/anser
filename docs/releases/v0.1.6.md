# Anser（雁信）0.1.6 Alpha

## 新功能

- **邮件签名**：按发件账号保存文字、HTML 或导入文件签名；编辑与预览并排显示，写信底栏可控制本封是否附加。签名随草稿保存，切换账号使用对应签名。
- **存档位置选择**：支持选择其他磁盘或文件夹保存完整邮件原件。先复制并校验，再切换位置；断盘明确提示，不自动改存到本机。统计、路径、完整性检查与管理入口集中呈现。
- **打开 EML 文件**：可在应用内选择 `.eml`，或通过 Finder 的“打开方式”使用雁信查看。展示原始日期、邮件正文和附件，支持本地应用预览及附件另存；不自动导入邮箱或改写原件。当前单文件上限为 64 MB。

## 改进与修复

- 设置页的后台任务、服务器状态、目录来源和最近活动默认折叠；统一卡片间距并按内容分组。
- 关于与更新中的项目仓库链接使用系统浏览器打开；正式应用隐藏示例邮箱入口。
- 添加邮箱时显示已知后缀、完整服务商名称，返回入口左对齐。
- 空白新邮件关闭直接舍弃，默认签名不计作用户输入；处理自动保存与关闭/发送的先后顺序，避免草稿再次生成。
- 邮件列表附件标识缩小并移至右侧。
- GitHub Pages 修复布局样式缺失，并与桌面共用界面、自动部署；公开网页只提供虚构示例，不连接或收发真实邮件。

## 安装与更新

提供 Apple Silicon（aarch64）与 Intel（x86_64）两种 macOS 安装包。使用组织版客户端可在“关于与更新”检查更新、下载安装并重启。应用数据、钥匙串标识及更新公钥保持不变。

安装后设置 EML 默认打开方式：Finder 选择 `.eml` → `⌘I` →「打开方式」选择「雁信」→「全部更改」。应用不会主动修改现有默认打开方式。

本版本仍为 Alpha。实际外置磁盘/故障恢复、大附件、部分服务商兼容性和新版本原位升级仍需持续验收；异步正文与完整保存规则扩展未进入本版本。本机 Google OAuth 测试配置不随公开包发布。

当前没有 Apple Developer ID 签名与公证；更新包签名用于验证更新来源，不等同于 Apple 公证。旧个人仓库客户端需要迁移到组织版才能使用新的更新地址。
