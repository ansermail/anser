# Anser · 雁信 0.1.18 Alpha

## 双语翻译稳定性

- 修复同段语义合并后，局部空文字片段被误判为整批失败的问题。保留全部片段标识，按整段检查译文；整段缺失、重复或未知标识仍会被拒绝。
- 翻译批次尽量保留同一段落的完整上下文，减少在加粗、链接等内联文字中间截断；超长段落仍遵守请求数量和大小限制。
- 更新模型提示和本地翻译缓存校验，保留原文、内联格式及原按钮内双语展示。

## 错误反馈与活动记录

- 将片段遗漏、重复、未知标识、整段空白、超长、无效字符、JSON 格式及提前结束分别反馈，便于定位失败原因。
- 最近活动记录安全的失败分类和同段合并数量，不保存邮件正文、译文、服务地址、密钥或原始模型返回；不会自动重复收费请求。

## 使用与更新

- 保持应用标识、账号、存档与原始 MIME 不变。模型调用仍只在主动翻译时发送可见正文文字，译文不进入原件、回复转发或原件打印。
- 首次通过 Homebrew 安装使用 `brew install --cask ansermail/tap/anser`；已有 Homebrew 安装可先 `brew update`，再 `brew upgrade --cask ansermail/tap/anser`。手动安装用户可使用应用内更新。
- 本版仍为 Alpha。应用未使用 Apple Developer ID 签名或公证，更新归档保留项目自有签名；首次打开可能需要在 macOS 隐私与安全性设置中确认。
