# Anser · 雁信 0.1.31 Alpha

## 免授权凭据库

- 邮箱密码/OAuth 令牌、代理密码和模型 API Key 改为保存在 AES-256-GCM 加密的本地凭据库 `credentials.vault`；32 字节密钥保存在登录钥匙串，由系统程序读取。应用重新构建、升级或电脑重启后不再要求输入登录钥匙串密码。
- macOS 会把钥匙串条目的访问控制绑定到创建它的程序版本，“始终允许”无法跨自签应用升级保留。新版由稳定的系统钥匙串程序创建和读取密钥，应用版本变化不影响读取，也不再需要逐账号或逐次授权。
- 首次启动会读取一次旧凭据库完成迁移，这是升级后唯一可能出现的一次系统授权。读取被拒绝或不可用时应用仍会启动，但旧账号需要在对应设置重新连接或填写密码/密钥；旧条目保留，不会自动删除。
- 登录钥匙串被锁定时应用提示解锁后重开，不在后台反复要求授权。凭据库损坏、无法解密或版本不受支持时保留原文件并提示备份，不会自动覆盖。
- 免授权意味着同一登录用户下的其他本机程序在知道路径时也能解密凭据库；这是不再反复授权的取舍。

## 兼容与更新

- 支持 Apple Silicon 与 Intel Mac，沿用既有应用标识 `dev.maildesk.desktop`、数据存储和更新公钥。
- 已有安装可通过应用内更新升级，Homebrew 配方继续在主仓库维护。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 签名或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。
