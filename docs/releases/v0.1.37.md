# Anser · 雁信 0.1.37 Alpha

本版修复邮件翻译失败和双语阅读排版问题。

- 翻译请求使用当前批次全部文字片段的精确返回模板；模型新增未知片段、遗漏、重复或重新编号时继续安全报错，不按位置猜配，也不自动重复收费请求。
- 邮件中的普通横排链接和页尾保持整行结构，空间不足时自然折行，不再把每个字段拆成一列；真实按钮仍保持为一个点击区域。
- 普通 HTML 译文折叠源码缩进，按钮译文使用紧凑行高，中文居中且不会因原按钮的居中行高或内边距异常增高。
- 连续图片切片只去除默认文字基线产生的白缝，保留作者设置的图片间距、换行和混合正文布局。

保留应用标识、已有账号、加密凭据库、完整邮件存档和更新公钥。提供 Apple Silicon / Intel Mac 与 Windows x64 安装及更新资源。

同一封真实模型邮件已在开发预览完成翻译、隐藏及再次显示复验；连续图片和双语按钮在开发预览中实际核对。图片切片、横排链接、按钮空白和额外片段均有自动回归覆盖。正式包安装及原位升级、Windows 与 Intel Mac 实机仍待独立验收，不以构建或资源核验代替。
