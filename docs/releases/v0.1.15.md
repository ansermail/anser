# Anser（雁信）0.1.15 Alpha

## 全局网络代理

- 在“设置与账号”中新增全局网络代理，可填写名称、SOCKS5/HTTP/HTTPS 类型、服务器地址、端口及可选用户名和密码。代理软件可自行决定哪些目标需要转发，无需逐个邮箱配置。
- 开启后，新建立的 IMAP/POP3 收件、SMTP 发件连接和应用内 OAuth 令牌请求使用该代理；关闭后恢复直连。代理密码保存在本机钥匙串。
- 默认代理连接失败时提示错误；可选择仅在代理连接或握手失败、邮件数据尚未发送时回退直连。代理隧道中的邮件服务器 TLS 身份仍按原服务器地址验证。

## 其他修复

- 纳入 0.1.14 发布后修复的通知点击时序问题：启动时未变化的空搜索不会取消待打开的通知邮件。

系统浏览器中的首次 OAuth 登录页面沿用浏览器自身网络设置。真实代理环境下的收发与令牌刷新仍需用户验收；本版不宣称所有服务商网络环境均已通过实测。

本版仍为 Alpha，沿用现有账号、本地存档标识和更新公钥。尚未提供 Apple Developer ID 签名或公证，正式包原位升级与钥匙串授权仍需实际验证。
