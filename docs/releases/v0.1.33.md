# Anser · 雁信 0.1.33 Alpha

## 阅读体验修复

- 修复部分邮件正文下半部分反复跳动：正文框在初始测量阶段会短暂出现内部滚动条，占用宽度后触发重新折行；把正文框拉高后滚动条消失，文字又折回原宽度。窗口宽度正好落在换行临界点时，两套排版会来回切换。现在测量期间正文框不再产生内部竖向滚动条，横向溢出仍可滚动并在高度中补偿。
- 修复右上角切换明暗主题后邮件正文不跟随变色、需要重新打开邮件才生效的问题：正文读取主题背景色的时机早于根元素应用深色类。现在切换主题时先应用外观类再渲染正文，浅色与深色都即时生效。
- 图片加载失败时除现有页面提示与重试外，会在窗口控制台打印失败图片的诊断信息，每张图只打印一次。地址、`srcset` 与替代文字全部经过 URL 编码，可直接粘贴查询；内联 `data:` 图片只记录长度，不输出内容。

## 邮件列表右键菜单

- 列表行右键菜单从单一的“标记为已读/未读”扩展为与阅读面板一致的操作：标记已读/未读、星标/取消星标、完整保存到本地、导出完整原始邮件、打印、归入本地文件夹、移到本地废纸篓或恢复、回复、全部回复、转发。
- 各项按当前状态显示对应文案，并标注可用快捷键；完整保存只对未完整保存的在线邮件出现。已读、星标与废纸篓操作沿用既有本地写入与撤销提示，不新增服务器端动作。

## 兼容与更新

- 支持 Apple Silicon 与 Intel Mac，沿用既有应用标识 `dev.maildesk.desktop`、数据存储和更新公钥。
- 已有安装可通过应用内更新升级，Homebrew 配方继续在主仓库维护。
- 本版仍为 Alpha。项目自签名与更新归档签名不等同于 Apple Developer ID 签名或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。

## 验收边界

- 本版覆盖自动回归、云端双架构构建与发布资源审计；正文跳动的修复结论来自真实邮件 HTML 的浏览器逐宽度复现与开发预览连续抓帧，正式安装后的默认打开、应用内原位升级和 Intel 实机运行仍需独立验收。
- 0.1.32 的标签在构建前的检查阶段未通过，没有生成任何发布资源；该版本未发布，本版沿用同一批修复并单独放宽两条大列表跨页导航用例的测试期限。
- 云端构建、正式发布资源及 Homebrew 同步结果以项目发布记录为准。
