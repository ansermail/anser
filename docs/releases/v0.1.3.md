# 雁信 0.1.3 Alpha

## 收取与保存

- 优化 IMAP 实时通知分发，优先下载新邮件；新通知到达时，旧邮件标记回读会让出收件箱。减少大邮箱检查时的重复数据库连接。
- 支持按服务器文件夹选择完整保存或在线阅读，保留已有本地存档。
- 支持单封、对话及批量完整补存，提供持久任务、暂停、继续、取消和失败重试；保存前核对原件与来源。
- 修复文本附件在 SMTP 传输中的换行变化，文件附件和内嵌图片使用 Base64，保留文件字节。
- 新增账号连接后展示保存引导、保存位置、已缓存邮件的待保存数量、失败项和最近成功时间；可填写服务器保留期用于提醒。

## 阅读、发信与规则

- 邮件列表可切换按对话或逐封显示，连续阅读可自动加载后续结果。
- SMTP 确认成功后，独立保存服务器已发送副本，核对上传结果；结果未确认时不盲目重复发送或上传。
- 支持主题、发件人等条件的服务器复制/移动规则，以及持久执行记录与失败反馈。
- 添加常见邮箱时预设地址后缀；OAuth 授权提供分阶段提示与取消。
- 修复在线邮件空正文误命中“未包含”条件。此版本的正文规则应在邮件完整保存后执行；新的在线正文异步核对与完整保存规则扩展仍在开发中，不包含在本次发布。

## 更新

沿用现有更新签名与存储标识，支持从旧版通过应用内更新下载安装并重启。首次安装可下载对应 Apple Silicon 或 Intel 的 DMG。

本版本仍为 Alpha。待保存数量只覆盖已发现的缓存邮件，0 待保存不代表服务器全部历史邮件已下载。睡眠/断网、大附件、部分服务商和复杂异常场景仍在验收中。

目前没有 Apple Developer ID 签名和公证，首次打开可能需要系统确认；更新签名校验不等同于 Apple 公证。

本机 Gmail 测试用 OAuth 配置不会放入公开发布包；正式 OAuth 配置与服务商发布验证仍待完善。
