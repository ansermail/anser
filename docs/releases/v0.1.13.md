# Anser（雁信）0.1.13 Alpha

## 邮件目录

- 点击账号名称或地址即可展开、收起服务器文件夹。加载期间只显示骨架屏，目录获取完成后一次展示。
- 有子目录的“其他文件夹”可查看父目录及子目录邮件汇总；点击子目录仍只看该目录。没有子目录且已隔离的占位文件夹不显示。
- 账号文件夹显示本机已同步可信邮件的未读数，并提供账号内的星标邮件入口；列表邮件右键可直接标记已读或未读。未读数可能与服务商网页中的服务器总数不同。
- Gmail 目录和向 IMAP 开放的标签按服务器返回动态展示，识别“重要邮件”。Gmail 网页侧栏隐藏偏好和分类展示尚未同步。

## 邮件打印

- 阅读页星标与本地删除之间新增打印按钮。系统打印页只包含当前单封邮件的主题、发件人、收件人、日期、正文和附件名称；不打印应用侧栏、列表或附件文件内容。

本版仍为 Alpha。真实 QQ、腾讯企业邮箱和 Gmail 目录及未读数、macOS 打印对话框、实际安装和原位升级仍需下载后验收；此前的富文本真实互发矩阵也继续保留。应用沿用现有数据目录、标识和更新签名；尚未提供 Apple Developer ID 签名或公证。
