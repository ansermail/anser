# Anser（雁信）0.1.5 Alpha

- 项目英文名统一为 Anser，中文名继续为“雁信”。项目包、可执行文件、邮件客户端标识及发布文件使用 Anser 名称。
- 代码和后续发布迁移到组织仓库 [ansermail/anser](https://github.com/ansermail/anser)。应用更新检查、发布页和安装包下载地址均使用新仓库。
- 发布检查为包含 205 封邮件与多次导航的集成测试设置独立超时，保留所有断言。
- 保留原应用存储与钥匙串标识，继续使用现有更新签名密钥；账号、本地存档和窗口偏好不因改名重置。
- 包含已验收的实时收取优化、保存范围/补存、保存引导、阅读模式和服务器操作功能，以及在线空正文误判修复。

本版本仍为 Alpha。异步正文规则与更完整的保存规则扩展尚未发布；本机 Google OAuth 测试配置不放入公开包。

此前安装包中的更新地址指向旧个人仓库。请在完成迁移更新后再删除旧仓库；仅克隆代码不会改变旧安装包的内置地址。

没有 Apple Developer ID 签名与公证，首次安装可能需要系统确认；更新签名校验不等同于 Apple 公证。
