# Anser（雁信）0.1.9 Alpha

## 列表与登录配置

- 邮件按实际时间从新到旧排列，修复日期时区不同导致的错序；对话阅读按实际时间从旧到新，原始邮件日期不变。
- 未读点不会被长标题挤掉，长标题正确省略；账号颜色点与未读标识分别说明。
- 原生包接入 Microsoft 公共桌面客户端配置，保留 Google 桌面 OAuth。微软实际邮箱地址/个人或企业预设必须匹配；应用授权不代表可用外部邮箱别名发送，SMTP 与刷新仍按服务商独立验证。

## 收件可靠性

- 实时连接每分钟进行轻量 NOOP 补查，继续优先使用 IDLE 推送；连接无变化时不额外下载原件，也不反复认证。补查与服务器主动推送分别记录，避免把补查结果记成即时推送。
- 补查发现收件箱变化后立即排队，也可让出旧只读下载。失败或断线丢弃旧连接并走现有重连机制；后台检查的用户设置保持。

## 已发送副本

- QQ 明确返回“Mail has saved by smtp!”时，改为等待新连接只读核对 SMTP 自动保存的副本。只读核对有限次退避，超过次数仍未确认时保留人工核对入口，不重新发信、不重复 APPEND。
- 旧版本中同一 QQ 回执留下的已拒绝记录自动进入只读核对；其他拒绝原因保留原处理方式。有已绑定目录标识的拒绝记录也可主动选择只读核对。
- 仍须唯一副本、UIDVALIDITY、完整 MIME 及不可变头字段核对通过才能显示成功。头字段不一致时仅显示字段名称，保留原件并阻止盲目重复上传。

## 安装与限制

提供 Apple Silicon / Intel macOS 安装包及签名更新归档，沿用应用存储/钥匙串标识、组织仓库更新地址与原更新公钥。原件、账号保存范围和存档路径不因更新改变。

仍为 Alpha，没有 Apple Developer ID 签名或公证；不同服务商、真实繁忙大附件、断网/睡眠恢复与正式原位升级仍需独立验收。轻量补查不保证服务器即时投递，补查结果也不等于 IDLE 即时验收。SMTP 接受、对方收到及服务器副本核对是各自独立的结果。
