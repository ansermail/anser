# Anser · 雁信 0.1.21 Alpha

## 设置更有条理

- 设置分为邮箱账号、本地存档、应用偏好、后台任务和关于雁信五类，查找功能更直接。
- 宽窗口使用左侧分类与右侧内容布局，较窄窗口自动切换为顶部分类导航。
- 统一卡片间距与信息层级，账号信息、通知与后台检查排列更清晰。
- 在设置内切换分类保留尚未保存的输入；规则页和保存提示中的“查看任务”直接进入后台任务。

## 后台任务交互

- 点击卡片标题、说明或箭头即可展开和收起，无需瞄准箭头。
- 手动刷新时图标旋转并显示“刷新中”，防止重复点击，快速读取也有清晰反馈。
- 刷新重新读取对应任务或活动记录，保持当前展开状态；数据完成读取后立即显示。

## 使用与更新

- 保持应用标识、账号、本地存档、原始 MIME 和既有更新公钥不变。
- Homebrew 配方由主仓库维护，已有安装可运行 `brew update` 后执行 `brew upgrade --cask ansermail/tap/anser`。
- 本版仍为 Alpha。项目自签名和更新归档签名不等同于 Apple Developer ID 或公证；首次打开仍可能需要按 macOS 隐私与安全性提示确认。
