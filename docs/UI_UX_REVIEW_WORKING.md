## 用户验收反馈：正文加载稳定性和缓存解释（2026-11-08）

- 核查截图对应真实邮件：`saved_locally=false`，`reading_cache` 记录为 17,132 字节，文件大小、SHA-256、头部哈希和 Message-ID 均匹配；本地读取及 Python MIME 解析约 20ms。该邮件只有可过期临时阅读缓存，因此状态仍显示“在线邮件 · 尚未完整保存”；完整保存按钮才会将该邮件转入长期原件。
- 原始 HTML 使用远端 Colfax 字体、OpenAI Logo 和 Mandrill 1×1 追踪图。当前网络测量两种字体约 1.0–1.4 秒返回 403，Logo 与追踪图约 1.1 秒返回；图片资源按既有约束不写磁盘缓存，且响应为 no-store。此前图片加载条位于 iframe 前并参与布局，超时后移除会推动正文。
- `MailContent` 初始正文仍使用原骨架；正文可读后，图片加载徽标和失败重试改为绝对定位在容器右上角，不参与正文高度。正常完成直接移除悬浮徽标；失败在相同位置显示重试，不再先上移再插入告警。失败提示仍可键盘操作。
- 内联 `@font-face` 由 `safeMailHtml`、外链样式由 `mail_styles.rs` 在缺少时补充 `font-display:swap`，远端字体等待时立即显示回退文字。未开放脚本、未改变 MIME/打印/转发，也未新增图片或字体磁盘缓存。
