# 跨版本更新说明工作点

## 目标（2026-10-16）

用户要求从当前版本升级至目标版本时，统计期间实际发布的版本，并逐个展示说明，例如 0.1.18 → 0.1.23。不按 patch 号码猜测发布次数，不只展示最新版。

## 设计与步骤

- 分支 codex/keychain-signing；钥匙串阶段提交 e639292 已推送，双架构签名验证独立进行；本功能另行提交。
- 原生后端只访问组织仓库 GitHub 公共 Releases API，逐页读取，使用全局代理与 TLS、超时和大小限制，不带邮箱或 GitHub 凭据。按语义版本筛选 (当前, 目标]，去重、倒序，排除草稿及不适用预发布。
- 更新中心沿用 shadcn Dialog/Card/Alert，显示版本范围/总数，每版名称、日期、完整安全 Markdown；说明为空明确标注。
- 历史失败明确提示“仅目标版本说明”，支持重试；不把不完整记录计作完整，不阻止已验证更新包下载/安装，不改变更新签名边界。
- 异步结果按范围及代际保护，关闭/切换目标/卸载不覆盖新状态；Pages 不调用真实原生/网络接口。

## 验证记录

后端分页/语义版本/发布状态/空说明/重复及缺失目标；前端数量、每版渲染、失败重试、异步过期、链接安全、原有下载/签名/写信阻止/重启；UI/格式/生产/Pages构建；开发预览与真实公共版本范围查询。
