3. 搜索规模：后端分页、全文索引/时间筛选、五万封指标。

- 按当前表单实际选择的保存范围，独立只读 IMAP 连接检查 EXAMINE/UID SEARCH 与分批 RFC822.SIZE；不取正文、不改标记、不触发保存或目录操作。
- 显示服务器位置数量（跨目录可能重复）、未缓存位置与预计新增原件字节；缺失 UIDVALIDITY、隔离目录、丢失大小或目录变化必须明确为未完成/保守估算，不能变成 0。
